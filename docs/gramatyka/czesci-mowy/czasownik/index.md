# Czasownik

Katalog przeznaczony na artykuły dotyczące czasownika.

## Proponowany rozwój

- znaczenie i rozpoznawanie czasowników,
- osoba i liczba,
- czasy,
- tryby,
- aspekt,
- strona czynna i bierna,
- bezokolicznik i formy nieosobowe,
- imiesłowy,
- przykłady użycia w tekstach.

Każde zagadnienie powinno otrzymać osobny plik Markdown w tym katalogu.
