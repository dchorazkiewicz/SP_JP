# Spójnik

<div class="conjunction-lesson" markdown>

<div class="indecl-lead">
<strong>Spójnik</strong> to nieodmienna część mowy, która łączy wyrazy, grupy wyrazów albo całe zdania. Pokazuje między nimi relację: dodawanie, wybór, przeciwstawienie, wynik, przyczynę, warunek, cel lub czas.
</div>
