# Jaką relację buduje przyimek?

<div class="preposition-lesson" markdown>

<div class="lesson-lead" markdown>

Przyimek nie nazywa samodzielnie przedmiotu ani czynności. Pokazuje, **jak jeden element odnosi się do drugiego**. Relacja może dotyczyć przestrzeni i czasu, ale również przyczyny, celu, sposobu, warunku, tematu albo źródła informacji.

</div>

## Ten sam dziedziniec oglądany z różnych stron

<div class="preposition-story" markdown>
  <div class="preposition-story__title">Przyimek ustawia relację</div>
  <div class="preposition-story__body" markdown>

> Rower stoi <span class="prep-focus">przed</span> <span class="governed-focus">bramą</span>.  
> Rower stoi <span class="prep-focus">za</span> <span class="governed-focus">bramą</span>.  
> Rower stoi <span class="prep-focus">przy</span> <span class="governed-focus">bramie</span>.  
> Rower stoi <span class="prep-focus">naprzeciwko</span> <span class="governed-focus">bramy</span>.

W każdym zdaniu występują te same dwa obiekty, lecz zmienia się ich wzajemne położenie. Przyimek organizuje relację, a nie nazywa samodzielnie miejsca.

</div>

## Miejsce, kierunek i droga

### Położenie

> dokument <span class="prep-focus">w</span> <span class="governed-focus">szufladzie</span>;  
> kubek <span class="prep-focus">na</span> <span class="governed-focus">stole</span>;  
> lampa <span class="prep-focus">nad</span> <span class="governed-focus">biurkiem</span>;  
> ławka <span class="prep-focus">między</span> <span class="governed-focus">drzewami</span>.

### Cel lub kierunek przemieszczenia

> wejść <span class="prep-focus">do</span> <span class="governed-focus">sali</span>;  
> położyć zeszyt <span class="prep-focus">na</span> <span class="governed-focus">stół</span>;  
> pobiec <span class="prep-focus">ku</span> <span class="governed-focus">bramie</span>;  
> schować się <span class="prep-focus">pod</span> <span class="governed-focus">dach</span>.

### Droga i obszar ruchu

> przejść <span class="prep-focus">przez</span> <span class="governed-focus">park</span>;  
> spacerować <span class="prep-focus">po</span> <span class="governed-focus">lesie</span>;  
> iść <span class="prep-focus">wzdłuż</span> <span class="governed-focus">brzegu</span>.

Położenie, cel ruchu i droga to różne relacje. Sam czasownik ruchu nie wystarcza do przewidzenia formy następnego wyrazu.

## Źródło i oddalanie się

> wrócić <span class="prep-focus">z</span> <span class="governed-focus">miasta</span>;  
> wyjść <span class="prep-focus">z</span> <span class="governed-focus">domu</span>;  
> wyjąć pudełko <span class="prep-focus">spod</span> <span class="governed-focus">łóżka</span>;  
> wyjść <span class="prep-focus">zza</span> <span class="governed-focus">drzewa</span>;  
> nadlecieć <span class="prep-focus">znad</span> <span class="governed-focus">jeziora</span>.

Formy **spod, zza, znad, sprzed** łączą znaczenie źródła z wcześniejszą relacją przestrzenną.

## Relacje czasu

> spotkanie <span class="prep-focus">o</span> <span class="governed-focus">dziewiątej</span>;  
> powrót <span class="prep-focus">po</span> <span class="governed-focus">obiedzie</span>;  
> praca <span class="prep-focus">od</span> <span class="governed-focus">rana</span> <span class="prep-focus">do</span> <span class="governed-focus">wieczora</span>;  
> rozmowa <span class="prep-focus">przed</span> <span class="governed-focus">lekcją</span>;  
> odpowiedź <span class="prep-focus">za</span> <span class="governed-focus">godzinę</span>.

Przyimek może wskazywać moment, początek, koniec, następstwo albo odległość czasową.

> Czekaliśmy <span class="prep-focus">przez</span> <span class="governed-focus">godzinę</span>. — długość trwania;  
> Wrócimy <span class="prep-focus">za</span> <span class="governed-focus">godzinę</span>. — moment w przyszłości.

## Przyczyna i okoliczność umożliwiająca

> mecz odwołano <span class="prep-focus">z powodu</span> <span class="governed-focus">burzy</span>;  
> spóźniliśmy się <span class="prep-focus">przez</span> <span class="governed-focus">korek</span>;  
> skończyliśmy wcześniej <span class="prep-focus">dzięki</span> <span class="governed-focus">pomocy</span>.

Przyimki nie są całkowicie wymienne. **Dzięki** zwykle przedstawia przyczynę jako korzystną, **przez** często wiąże się z niepożądanym skutkiem, a **z powodu** jest bardziej neutralne.

## Cel, przeznaczenie i odbiorca

> pójść <span class="prep-focus">po</span> <span class="governed-focus">lekarstwo</span>;  
> zbierać pieniądze <span class="prep-focus">na</span> <span class="governed-focus">wycieczkę</span>;  
> przygotować salę <span class="prep-focus">dla</span> <span class="governed-focus">gości</span>;  
> spotkać się <span class="prep-focus">w celu</span> <span class="governed-focus">omówienia planu</span>.

Porównaj:

> prezent <span class="prep-focus">dla</span> <span class="governed-focus">Marty</span> — odbiorca;  
> prezent <span class="prep-focus">na</span> <span class="governed-focus">urodziny Marty</span> — okazja lub przeznaczenie.

## Warunek, przeciwieństwo i przyzwolenie

> <span class="prep-focus">W razie</span> <span class="governed-focus">awarii</span> użyj drugiego wejścia.  
> Wyruszyli <span class="prep-focus">mimo</span> <span class="governed-focus">deszczu</span>.  
> Postąpili <span class="prep-focus">wbrew</span> <span class="governed-focus">ostrzeżeniom</span>.  
> Głosowali <span class="prep-focus">przeciw</span> <span class="governed-focus">zmianie</span>.

**Mimo deszczu** pokazuje przeszkodę, która nie zatrzymała działania. **Wbrew ostrzeżeniom** wskazuje działanie sprzeczne z radą lub oczekiwaniem.

## Sposób, narzędzie i pośrednictwo

> otworzyć drzwi <span class="prep-focus">za pomocą</span> <span class="governed-focus">klucza</span>;  
> przesłać dane <span class="prep-focus">za pośrednictwem</span> <span class="governed-focus">formularza</span>;  
> pracować <span class="prep-focus">bez</span> <span class="governed-focus">pośpiechu</span>;  
> działać <span class="prep-focus">według</span> <span class="governed-focus">planu</span>.

Wyrażenie przyimkowe może przekazywać informację podobną do przysłówka:

> pracować bez pośpiechu — pracować spokojnie.

Podobieństwo funkcji nie oznacza jednak tej samej budowy gramatycznej.

## Temat, odniesienie i podstawa

> rozmowa <span class="prep-focus">o</span> <span class="governed-focus">filmie</span>;  
> uwagi <span class="prep-focus">do</span> <span class="governed-focus">raportu</span>;  
> decyzja <span class="prep-focus">wobec</span> <span class="governed-focus">zmian</span>;  
> wniosek <span class="prep-focus">na podstawie</span> <span class="governed-focus">danych</span>.

Przyimki budują nie tylko relacje widoczne w przestrzeni. Porządkują także myśli, argumenty i zależności pojęciowe.

## „W”, „na”, „do” nie podlegają jednej prostej regule

> być <span class="prep-focus">w</span> <span class="governed-focus">szkole</span> — iść <span class="prep-focus">do</span> <span class="governed-focus">szkoły</span>;  
> być <span class="prep-focus">na</span> <span class="governed-focus">poczcie</span> — iść <span class="prep-focus">na</span> <span class="governed-focus">pocztę</span>;  
> być <span class="prep-focus">w</span> <span class="governed-focus">kinie</span> — iść <span class="prep-focus">do</span> <span class="governed-focus">kina</span>;  
> być <span class="prep-focus">na</span> <span class="governed-focus">koncercie</span> — iść <span class="prep-focus">na</span> <span class="governed-focus">koncert</span>.

Wiele połączeń jest utrwalonych przez zwyczaj językowy i najlepiej uczyć się ich parami.

## Dopiero teraz rodzaje budowy przyimków

### Proste

> w, z, do, od, na, pod, nad, przy, przed, za, o, po, ku, przez, bez, dla.

### Złożone

> spod, znad, zza, sprzed, poprzez, ponad, pomiędzy.

### Wtórne i wielowyrazowe

> podczas, według, wobec, wskutek, względem, wzdłuż;  
> z powodu, ze względu na, w związku z, na podstawie, w celu.

Granica między pojedynczym przyimkiem wtórnym a utrwalonym wyrażeniem przyimkowym nie zawsze jest opisywana jednakowo. Najważniejsze jest rozpoznanie całej konstrukcji.

## Jeden przyimek, wiele znaczeń

> wrócić <span class="prep-focus">po</span> <span class="governed-focus">lekcji</span> — czas;  
> iść <span class="prep-focus">po</span> <span class="governed-focus">zakupy</span> — cel;  
> spacerować <span class="prep-focus">po</span> <span class="governed-focus">parku</span> — przestrzeń;  
> rozdać <span class="prep-focus">po</span> <span class="governed-focus">dwa bilety</span> — podział.

> stać <span class="prep-focus">za</span> <span class="governed-focus">domem</span> — miejsce;  
> wrócić <span class="prep-focus">za</span> <span class="governed-focus">godzinę</span> — czas;  
> podziękować <span class="prep-focus">za</span> <span class="governed-focus">pomoc</span> — przedmiot wdzięczności.

Znaczenie ustalamy z całego połączenia i zdania.

## Jak rozpoznawać znaczenie relacji?

<div class="preposition-step-list">
  <div class="preposition-step"><strong>Znajdź całe wyrażenie przyimkowe.</strong></div>
  <div class="preposition-step"><strong>Ustal, jakie dwa elementy zostają połączone.</strong></div>
  <div class="preposition-step"><strong>Odczytaj relację z całego zdania.</strong></div>
  <div class="preposition-step"><strong>Rozróżnij położenie, cel, drogę i źródło ruchu.</strong></div>
  <div class="preposition-step"><strong>Przy relacjach abstrakcyjnych nazwij temat, odbiorcę, podstawę albo zgodność.</strong></div>
  <div class="preposition-step"><strong>Przy konstrukcjach wielowyrazowych ustal ich pełny zakres.</strong></div>
</div>

<div class="preposition-summary">
<h3>Podsumowanie</h3>
<ul>
  <li>Przyimki wyrażają relacje przestrzenne, czasowe, przyczynowe, celowe, sposobowe i abstrakcyjne.</li>
  <li>Położenie, kierunek, droga i źródło ruchu to odrębne relacje.</li>
  <li>Ten sam przyimek może wyrażać wiele znaczeń zależnie od całego zdania.</li>
  <li>Klasyfikację budowy przyimka wprowadzamy po zrozumieniu jego funkcji.</li>
  <li>Następna lekcja pokaże, jak znaczenie relacji wpływa na przypadek kolejnego wyrazu.</li>
</ul>
