# Przyimek

<div class="preposition-lesson" markdown>

<div class="indecl-lead">
<strong>Przyimek</strong> to nieodmienna część mowy, która łączy się najczęściej z rzeczownikiem, zaimkiem albo liczebnikiem i wskazuje relacje miejsca, czasu, przyczyny, celu, sposobu lub zależności. Przyimek narzuca określony przypadek.
</div>

<div class="indecl-concept-grid">
  <div class="indecl-concept-card"><strong>Nie działa sam</strong>Przyimek zwykle tworzy wyrażenie z innym wyrazem: „w domu”, „bez ciebie”, „dzięki pomocy”.</div>
  <div class="indecl-concept-card"><strong>Narzuca przypadek</strong>Mówimy „do szkoły”, ale „ku szkole” i „ze szkołą”.</div>
  <div class="indecl-concept-card"><strong>Przypadek może zmienić sens</strong>„Na stole” oznacza miejsce, a „na stół” — kierunek.</div>
  <div class="indecl-concept-card"><strong>Jeden przyimek może mieć kilka znaczeń</strong>„Po lekcji” oznacza czas, a „po schodach” — drogę ruchu.</div>
