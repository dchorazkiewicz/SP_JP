# Przysłówek

<div class="adverb-lesson" markdown>

<div class="indecl-lead">
<strong>Przysłówek</strong> to nieodmienna część mowy, która najczęściej określa czasownik, przymiotnik albo inny przysłówek. Odpowiada między innymi na pytania <strong>jak?</strong>, <strong>gdzie?</strong>, <strong>kiedy?</strong>, <strong>dlaczego?</strong> i <strong>w jakim stopniu?</strong>.
</div>

## Jak korzystać z tego działu?

Przysłówek nie odmienia się przez przypadki, osoby ani rodzaje, ale może zmieniać stopień natężenia i pełnić różne funkcje w zdaniu. Dlatego obserwujemy go zawsze razem z wyrazem, który określa.
