# Przymiotnik

Katalog na artykuły dotyczące przymiotnika.

## Tematy

- rozpoznawanie przymiotników,
- związek przymiotnika z rzeczownikiem,
- odmiana przez przypadki, liczby i rodzaje,
- stopniowanie,
- funkcje w zdaniu,
- przykłady użycia.

Każdy temat może otrzymać osobny plik Markdown w tym katalogu.
