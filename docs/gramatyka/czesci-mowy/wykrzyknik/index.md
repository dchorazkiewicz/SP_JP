# Wykrzyknik

<div class="interjection-lesson" markdown>

<div class="indecl-lead">
<strong>Wykrzyknik</strong> to nieodmienny wyraz albo utrwalony zwrot, który wyraża emocję, reakcję, wolę, wezwanie lub naśladuje dźwięk. Często może tworzyć samodzielną wypowiedź: <em>Ach! Ojej! Halo! Stop! Bach!</em>
</div>

<div class="indecl-concept-grid">
  <div class="indecl-concept-card"><strong>Może być samodzielną wypowiedzią</strong>„Ojej!” przekazuje reakcję bez czasownika i rzeczownika.</div>
  <div class="indecl-concept-card"><strong>Znaczenie zależy od intonacji</strong>„Och” może wyrażać zachwyt, ulgę, zmęczenie albo rozczarowanie.</div>
  <div class="indecl-concept-card"><strong>Może kierować zachowaniem</strong>„Hej!”, „halo!”, „stop!” przyciągają uwagę albo zatrzymują działanie.</div>
  <div class="indecl-concept-card"><strong>Naśladuje dźwięk</strong>„Bach”, „stuk”, „miau”, „tik-tak” odtwarzają odgłosy świata.</div>
