# Wykrzykniki w tekście

<div class="interjection-lesson" markdown>

<div class="indecl-lead">
Poniższy tekst ma 50 zdań. Wykrzykniki zostały wyróżnione według funkcji. Obserwuj, jak interpunkcja i kontekst zmieniają emocję, wezwanie albo dźwięk.
</div>

    <h2>Nocna próba w teatrze</h2>
