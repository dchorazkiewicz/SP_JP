# Partykuła

<div class="particle-lesson" markdown>

<div class="indecl-lead">
<strong>Partykuła</strong> to nieodmienny wyraz, który modyfikuje znaczenie wypowiedzi: zaprzecza, wzmacnia, ogranicza, wyraża przypuszczenie, pytanie, życzenie, rozkaz albo stosunek mówiącego do informacji.
</div>
