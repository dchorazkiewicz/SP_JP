# Zaimek

<div class="pronoun-lesson" markdown>

<div class="lesson-lead">
<strong>Zaimek</strong> nie nazywa osoby, rzeczy, cechy, liczby ani okoliczności wprost. Wskazuje na nie, zastępuje wcześniejsze wyrazy albo odsyła do sytuacji wypowiedzi: <em>ja, ty, on, ten, mój, ktoś, każdy, tutaj</em>.
</div>

## Jak korzystać z tego działu?

Zaimek trzeba zawsze interpretować w kontekście. Forma **on** niczego dokładnie nie nazywa, dopóki nie wiemy, do kogo lub czego się odnosi. Dlatego przykłady w tym rozdziale są pełnymi zdaniami i krótkimi fragmentami tekstu.
