# Słowotwórstwo

Dział opisuje budowę wyrazów i sposoby tworzenia nowych jednostek leksykalnych.

## Zakres działu

- wyraz podstawowy i pochodny,
- podstawa słowotwórcza,
- formanty,
- rodzina wyrazów,
- rdzeń i oboczności,
- wyrazy złożone,
- skrótowce,
- analiza słowotwórcza.

Nowe artykuły będą dodawane jako osobne pliki Markdown w tym katalogu.
