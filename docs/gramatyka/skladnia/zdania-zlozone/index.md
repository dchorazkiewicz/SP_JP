# Zdania złożone

Porównaj:

> Marta musi przygotować raport.
>
> Marta przygotowała raport i wysłała go dyrekcji.

W pierwszym wypowiedzeniu kilka form tworzy jedno pełne orzeczenie. W drugim są dwie główne informacje. Zdanie złożone zawiera co najmniej dwie pełne informacje orzeczeniowe.

Najpierw znajdujemy pełne orzeczenia, potem granice części, następnie relację między nimi, a dopiero na końcu typ i interpunkcję.
