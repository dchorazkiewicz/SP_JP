# Zdania podmiotowe i orzecznikowe

## Dwie funkcje całego zdania

> To, że termin przesunięto, zaskoczyło uczestników.

Pytamy **co zaskoczyło?**. Cała część **że termin przesunięto** pełni funkcję podmiotu.

> Problem jest taki, że termin przesunięto.

Pytamy **jaki jest problem?**. Ta sama treść rozwija wskaźnik **taki** i pełni funkcję orzecznika.

```text
podmiotowe:     co zaskoczyło? → że termin przesunięto
orzecznikowe:   jaki jest problem? → że termin przesunięto
```

## Dlaczego spójnik nie wystarcza

> To, że Marta nie przyszła, było problemem. — podmiotowe.
>
> Problem był taki, że Marta nie przyszła. — orzecznikowe.

W obu zdaniach występuje **że**. Typ zmienia miejsce zajmowane wobec części nadrzędnej.

## Zamiana na prostszy składnik

> To, że pada, martwi mnie. → **Deszcz** martwi mnie.
>
> Cel jest taki, żeby zakończyć pracę. → Celem jest **zakończenie pracy**.

Zastąpienie rzeczownikiem ujawnia funkcję.

## Intencja

Konstrukcja podmiotowa pozwala uczynić całe zdarzenie tematem. Konstrukcja orzecznikowa służy wyjaśnieniu, na czym polega problem, cel albo trudność.

## Procedura

1. Znajdź orzeczenie części nadrzędnej.
2. Pytanie **kto? co?** wskazuje typ podmiotowy.
3. Pytania **jaki jest? kim jest? czym jest?** wskazują typ orzecznikowy.
4. Sprawdź rolę **to** lub **taki**.
5. Nazwij typ dopiero po ustaleniu funkcji.
