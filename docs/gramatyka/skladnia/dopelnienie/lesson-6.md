# Dopełnienie a okolicznik

<div class="object-lesson" markdown>

<div class="object-lead">
Dopełnienie i okolicznik mogą mieć podobną formę, zwłaszcza gdy oba są wyrażeniami przyimkowymi. Rozstrzyga nie sam przyimek, lecz relacja z czasownikiem: dopełnienie uzupełnia wymaganie czasownika, a okolicznik opisuje warunki czynności.
</div>

## Ten sam przyimek, inna funkcja

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">dopełnienie</span><p>Marta <span class="object-predicate">rozmawia</span> <span class="object-mark object-mark--prepositional">z kolegą</span>.</p><p>Czasownik otwiera miejsce dla rozmówcy.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">okolicznik</span><p>Marta <span class="object-predicate">mieszka</span> z kolegą.</p><p>Wyrażenie opisuje towarzyszenie w sytuacji mieszkania.</p></div>
</div>

## Czasownik wymagający przyimka

<div class="object-series">
  <div class="object-row"><span class="object-badge">czekać na</span><p>Marta <span class="object-predicate">czeka</span> <span class="object-mark object-mark--prepositional">na autobus</span>.</p><span class="object-note">wymaganie</span></div>
  <div class="object-row"><span class="object-badge">myśleć o</span><p>Marta <span class="object-predicate">myśli</span> <span class="object-mark object-mark--prepositional">o projekcie</span>.</p><span class="object-note">wymaganie</span></div>
  <div class="object-row"><span class="object-badge">zależeć od</span><p>Wynik <span class="object-predicate">zależy</span> <span class="object-mark object-mark--prepositional">od pogody</span>.</p><span class="object-note">wymaganie</span></div>
  <div class="object-row"><span class="object-badge">polegać na</span><p>Zadanie <span class="object-predicate">polega</span> <span class="object-mark object-mark--prepositional">na porównaniu danych</span>.</p><span class="object-note">wymaganie</span></div>
</div>

Usunięcie tych wyrażeń pozostawia znaczenie wyraźnie niepełne: **czeka — na co?**, **myśli — o czym?**, **zależy — od czego?**

## Swobodna informacja o miejscu

> Marta <span class="object-predicate">pracuje</span> w bibliotece.

> Marta <span class="object-predicate">pracuje</span> przy oknie.

> Marta <span class="object-predicate">pracuje</span> na drugim piętrze.

Czasownik **pracować** nie narzuca konkretnego miejsca. Wyrażenia można zmieniać lub usuwać bez naruszenia podstawowego schematu zdania.

## Kierunek jako okoliczność

> Marta <span class="object-predicate">jedzie</span> do miasta.

> Marta <span class="object-predicate">wraca</span> z biura.

> Marta <span class="object-predicate">wchodzi</span> do sali.

W szkolnej analizie takie wyrażenia są zwykle okolicznikami miejsca lub kierunku, choć czasowniki ruchu silnie przewidują informację o trasie.

## Narzędnik: obiekt czy sposób?

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">dopełnienie</span><p>Anna <span class="object-predicate">kieruje</span> <span class="object-mark object-mark--indirect">zespołem</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">okolicznik środka</span><p>Anna <span class="object-predicate">jedzie</span> autobusem.</p></div>
</div>

Forma narzędnika jest taka sama, ale czasownik **kierować** wymaga obiektu zarządzania, natomiast **autobusem** określa sposób przemieszczania się.

## Osoba jako dopełnienie lub towarzysz

> Marta <span class="object-predicate">opiekuje się</span> <span class="object-mark object-mark--indirect">dzieckiem</span>. — dopełnienie.

> Marta <span class="object-predicate">spaceruje</span> z dzieckiem. — okolicznik towarzyszenia.

> Marta <span class="object-predicate">rozmawia</span> <span class="object-mark object-mark--prepositional">z dzieckiem</span>. — dopełnienie wymagane przez znaczenie rozmowy.

## Test usuwania

Porównaj:

> Marta czeka **na autobus**.

> Marta czeka.

Drugie zdanie jest możliwe, ale pozostawia otwarte pytanie o przedmiot czekania.

> Marta pracuje **rano**.

> Marta pracuje.

Drugie zdanie zachowuje pełny podstawowy schemat. To przemawia za okolicznikiem.

## Test zamiany

Jeżeli przy tym samym czasowniku można swobodnie podmieniać okoliczności, mamy zwykle okolicznik:

- pracuje **rano**;
- pracuje **w domu**;
- pracuje **uważnie**;
- pracuje **dla pieniędzy**.

Jeżeli zmiana przyimka niszczy schemat, mamy silniejszą rekcję:

- myśli **o projekcie**;
- zależy **od decyzji**;
- czeka **na odpowiedź**.

<div class="object-summary">
<h3>Granica przebiega między wymaganiem a okolicznością</h3>
Dopełnienie uzupełnia strukturę otwartą przez czasownik. Okolicznik opisuje miejsce, czas, sposób, przyczynę albo inne warunki czynności. Nie każda konstrukcja daje się jednak rozstrzygnąć bezdyskusyjnie.
