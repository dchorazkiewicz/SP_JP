# Bezokolicznik i zdanie dopełnieniowe

<div class="object-lesson" markdown>

<div class="object-lead">
Dopełnienie nie musi być rzeczownikiem. Czasownik może wymagać bezokolicznika albo całego zdania podrzędnego, które nazywa treść wiedzy, wypowiedzi, pytania, decyzji lub zamiaru.
</div>

## Bezokolicznik jako uzupełnienie

<div class="object-series">
  <div class="object-row"><span class="object-badge">chcieć</span><p>Marta <span class="object-predicate">chce</span> <span class="object-mark object-mark--clausal">wyjechać wcześniej</span>.</p><span class="object-note">czego chce?</span></div>
  <div class="object-row"><span class="object-badge">lubić</span><p>Paweł <span class="object-predicate">lubi</span> <span class="object-mark object-mark--clausal">czytać reportaże</span>.</p><span class="object-note">co lubi?</span></div>
  <div class="object-row"><span class="object-badge">obiecać</span><p>Marta <span class="object-predicate">obiecała</span> <span class="object-mark object-mark--clausal">wysłać dokument</span>.</p><span class="object-note">co obiecała?</span></div>
  <div class="object-row"><span class="object-badge">próbować</span><p>Technik <span class="object-predicate">próbuje</span> <span class="object-mark object-mark--clausal">uruchomić urządzenie</span>.</p><span class="object-note">czego próbuje?</span></div>
</div>

Bezokolicznik nazywa czynność, która uzupełnia znaczenie czasownika nadrzędnego.

## Bezokolicznik a część orzeczenia złożonego

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">orzeczenie złożone</span><p>Marta <strong>musi wyjść</strong>.</p><p>W szkolnej analizie całe połączenie tworzy orzeczenie.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">uzupełnienie bezokolicznikowe</span><p>Marta <strong>obiecała</strong> wyjść wcześniej.</p><p>Bezokolicznik nazywa treść obietnicy.</p></div>
</div>

Granica nie zawsze jest całkowicie ostra. Przy czasownikach **chcieć, zamierzać, potrafić** różne opisy mogą inaczej dzielić konstrukcję.

## Zdanie z „że”

<div class="object-series">
  <div class="object-row"><span class="object-badge">wiedza</span><p>Marta <span class="object-predicate">wie</span>, <span class="object-mark object-mark--clausal">że termin się zmienił</span>.</p><span class="object-note">co wie?</span></div>
  <div class="object-row"><span class="object-badge">informacja</span><p>Kierowniczka <span class="object-predicate">powiedziała</span>, <span class="object-mark object-mark--clausal">że spotkanie rozpocznie się później</span>.</p><span class="object-note">co powiedziała?</span></div>
  <div class="object-row"><span class="object-badge">przekonanie</span><p>Zespół <span class="object-predicate">uważa</span>, <span class="object-mark object-mark--clausal">że wynik jest poprawny</span>.</p><span class="object-note">co uważa?</span></div>
</div>

Całe zdanie podrzędne pełni funkcję odpowiadającą dopełnieniu.

## Zdanie z „czy”

> Marta <span class="object-predicate">pyta</span>, <span class="object-mark object-mark--clausal">czy raport jest gotowy</span>.

> Nie <span class="object-predicate">wiem</span>, <span class="object-mark object-mark--clausal">czy Paweł przyjdzie</span>.

> Kierowniczka <span class="object-predicate">sprawdziła</span>, <span class="object-mark object-mark--clausal">czy wszystkie drzwi są zamknięte</span>.

Zdania te wyrażają treść pytania, niewiedzy albo kontroli.

## Zdanie pytajne zależne

<div class="object-series">
  <div class="object-row"><span class="object-badge">kto</span><p>Nie <span class="object-predicate">wiem</span>, <span class="object-mark object-mark--clausal">kto podpisał dokument</span>.</p><span class="object-note">czego nie wiem?</span></div>
  <div class="object-row"><span class="object-badge">gdzie</span><p>Marta <span class="object-predicate">sprawdziła</span>, <span class="object-mark object-mark--clausal">gdzie zapisano plik</span>.</p><span class="object-note">co sprawdziła?</span></div>
  <div class="object-row"><span class="object-badge">kiedy</span><p>Zespół <span class="object-predicate">ustalił</span>, <span class="object-mark object-mark--clausal">kiedy rozpocznie test</span>.</p><span class="object-note">co ustalił?</span></div>
</div>

Wyraz pytajny pełni funkcję wewnątrz zdania podrzędnego, a całe zdanie uzupełnia czasownik nadrzędny.

## Mowa zależna i niezależna

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">mowa niezależna</span><p>Marta powiedziała: „Raport jest gotowy”.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">mowa zależna</span><p>Marta powiedziała, <span class="object-mark object-mark--clausal">że raport jest gotowy</span>.</p></div>
</div>

W mowie zależnej treść wypowiedzi zostaje włączona do zdania jako uzupełnienie czasownika **powiedziała**.

## Bezokolicznik i zdanie mogą przekazywać podobną treść

> Marta obiecała <span class="object-mark object-mark--clausal">wysłać raport</span>.

> Marta obiecała, <span class="object-mark object-mark--clausal">że wyśle raport</span>.

Pierwsza konstrukcja jest bardziej zwarta. Druga zawiera osobową formę czasownika i tworzy pełne zdanie podrzędne.

## Różni wykonawcy

> Marta poprosiła Pawła <span class="object-mark object-mark--clausal">o przygotowanie sali</span>.

> Marta poprosiła Pawła, <span class="object-mark object-mark--clausal">żeby przygotował salę</span>.

W drugim zdaniu wykonawcą czynności **przygotował** jest Paweł, a nie Marta.

<div class="object-summary">
<h3>Treść również może być dopełnieniem</h3>
Czasownik może wymagać nie tylko osoby lub rzeczy, lecz także czynności, pytania, wiadomości albo całej sytuacji. Dlatego funkcję dopełnienia może pełnić bezokolicznik lub zdanie podrzędne.
</div>
