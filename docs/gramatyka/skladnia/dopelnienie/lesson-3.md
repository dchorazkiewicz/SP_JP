# Dopełnienie bliższe i dalsze

<div class="object-lesson" markdown>

<div class="object-lead">
Dopełnienie bliższe jest najmocniej związane z czasownikiem przechodnim i może zwykle stać się podmiotem strony biernej. Dopełnienie dalsze uzupełnia znaczenie orzeczenia, ale nie przechodzi w ten sposób do pozycji podmiotu.
</div>

## Test strony biernej

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">strona czynna</span><p>Marta <span class="object-predicate">napisała</span> <span class="object-mark object-mark--direct">raport</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">strona bierna</span><p><strong>Raport</strong> został napisany przez Martę.</p></div>
</div>

Składnik **raport** był dopełnieniem w stronie czynnej, a po przekształceniu stał się podmiotem. To najważniejszy test dopełnienia bliższego.

## Typowe dopełnienia bliższe

- Zespół <span class="object-predicate">analizuje</span> <span class="object-mark object-mark--direct">wyniki</span>.
- Technik <span class="object-predicate">naprawił</span> <span class="object-mark object-mark--direct">urządzenie</span>.
- Kierowniczka <span class="object-predicate">podpisała</span> <span class="object-mark object-mark--direct">umowę</span>.
- Uczniowie <span class="object-predicate">przeczytali</span> <span class="object-mark object-mark--direct">tekst</span>.

Możliwe przekształcenia:

- **wyniki zostały przeanalizowane**;
- **urządzenie zostało naprawione**;
- **umowa została podpisana**;
- **tekst został przeczytany**.

## Dopełnienie dalsze

<div class="object-series">
  <div class="object-row"><span class="object-badge">celownik</span><p>Marta <span class="object-predicate">pomaga</span> <span class="object-mark object-mark--indirect">koledze</span>.</p><span class="object-note">komu?</span></div>
  <div class="object-row"><span class="object-badge">dopełniacz</span><p>Zespół <span class="object-predicate">potrzebuje</span> <span class="object-mark object-mark--indirect">czasu</span>.</p><span class="object-note">czego?</span></div>
  <div class="object-row"><span class="object-badge">narzędnik</span><p>Anna <span class="object-predicate">kieruje</span> <span class="object-mark object-mark--indirect">działem</span>.</p><span class="object-note">czym?</span></div>
  <div class="object-row"><span class="object-badge">przyimek</span><p>Marta <span class="object-predicate">myśli</span> <span class="object-mark object-mark--prepositional">o projekcie</span>.</p><span class="object-note">o czym?</span></div>
</div>

Nie tworzymy naturalnie zdań: „kolega jest pomagany”, „czas jest potrzebowany” ani „projekt jest myślany”. To sygnał, że składniki nie są dopełnieniami bliższymi.

## Dwa dopełnienia przy jednym czasowniku

> Marta <span class="object-predicate">wysłała</span> <span class="object-mark object-mark--indirect">kierownikowi</span> <span class="object-mark object-mark--direct">raport</span>.

- **raport** — dopełnienie bliższe;
- **kierownikowi** — dopełnienie dalsze.

Po zmianie strony:

> <strong>Raport</strong> został wysłany kierownikowi przez Martę.

Do podmiotu przechodzi **raport**, a **kierownikowi** pozostaje dopełnieniem.

## Dopełnienie bliższe w dopełniaczu

Nie zawsze występuje ono w bierniku:

> Marta <span class="object-predicate">napiła się</span> <span class="object-mark object-mark--direct">wody</span>.

> Technik <span class="object-predicate">użył</span> <span class="object-mark object-mark--direct">miernika</span>.

> Zespół <span class="object-predicate">dokonał</span> <span class="object-mark object-mark--direct">pomiaru</span>.

Klasyfikacja zależy od tego, jak dany czasownik buduje stronę bierną i jak silnie wiąże się z uzupełnieniem.

## Ograniczenia testu

Nie każda gramatycznie możliwa strona bierna brzmi naturalnie w codziennym języku. Porównaj:

> Marta <span class="object-predicate">ma</span> <span class="object-mark object-mark--direct">samochód</span>.

Zdanie „samochód jest miany przez Martę” jest nienaturalne. Mimo to **samochód** uzupełnia czasownik **mieć** podobnie jak typowe dopełnienie bliższe. Test strony biernej jest bardzo użyteczny, ale nie działa mechanicznie dla wszystkich czasowników.

## Czasownik przechodni i nieprzechodni

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">przechodni</span><p>Marta <span class="object-predicate">otworzyła</span> <span class="object-mark object-mark--direct">okno</span>.</p><p>Możliwa strona bierna: okno zostało otwarte.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">nieprzechodni</span><p>Marta <span class="object-predicate">przyszła</span> rano.</p><p>Czasownik nie otwiera miejsca dla dopełnienia bliższego.</p></div>
</div>

<div class="object-summary">
<h3>Dopełnienie bliższe zmienia pozycję w stronie biernej</h3>
To najlepszy praktyczny test, ale zawsze trzeba uwzględnić znaczenie i naturalność konstrukcji. Dopełnienie dalsze pozostaje zależne od czasownika, lecz nie staje się podmiotem strony biernej.
</div>
