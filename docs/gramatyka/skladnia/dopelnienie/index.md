# Dopełnienie

<div class="object-lesson" markdown>

## Od głównej informacji do jej uczestników

Porównaj:

> <span class="subject-mark subject-mark--grammatical"><strong>Marta</strong></span> <span class="object-predicate">czyta</span>.

> <span class="subject-mark subject-mark--grammatical"><strong>Marta</strong></span> <span class="object-predicate">czyta</span> <span class="object-mark object-mark--basic"><strong>raport</strong></span>.

> <span class="subject-mark subject-mark--grammatical"><strong>Marta</strong></span> <span class="object-predicate">czyta</span> <span class="object-mark object-mark--basic"><strong>raport</strong></span> w biurze.

W każdym zdaniu:

- **Marta** jest osobą, o której coś stwierdzamy — podmiotem;
- **czyta** przekazuje główną informację — orzeczeniem;
- **raport** nazywa rzecz objętą czytaniem;
- **w biurze** mówi, gdzie odbywa się czynność.

Wyraz **raport** jest silniej związany ze znaczeniem czasownika niż informacja o miejscu. Uzupełnia odpowiedź na pytanie, **co Marta czyta**. Taki składnik nazywamy **dopełnieniem**.

<div class="object-concept">
  <span class="object-concept__label">Pojęcie</span>
  <strong>Dopełnienie</strong>
  <p>To część zdania zależna od orzeczenia albo od jednego z jego składników. Nazywa osobę, rzecz, treść lub czynność związaną z tym, co wyraża orzeczenie.</p>
</div>

## Podmiot, orzeczenie i dopełnienie pełnią różne zadania

> <span class="subject-mark subject-mark--grammatical"><strong>Kierowniczka</strong></span> <span class="object-predicate">przekazała</span> <span class="object-mark object-mark--basic"><strong>technikowi</strong></span> <span class="object-mark object-mark--basic"><strong>instrukcję</strong></span>.

<div class="object-tree">przekazała
├── kto przekazał? → kierowniczka → podmiot
├── komu? → technikowi → dopełnienie
└── co? → instrukcję → dopełnienie</div>

Orzeczenie organizuje zdanie. Podmiot wskazuje osobę lub rzecz, o której orzekamy. Dopełnienia zajmują miejsca otwarte przez znaczenie czasownika: odbiorcy i przekazywanego przedmiotu.

<div class="object-summary">
<h3>Dopełnienie nie jest „tym, co zostało po znalezieniu podmiotu”</h3>
<p>Każdy składnik trzeba uzasadnić. Rzeczownik może być podmiotem, dopełnieniem, częścią orzeczenia albo wyrazem głównym grupy zawierającej przydawki. O funkcji decyduje relacja z innymi częściami zdania.</p>
</div>

## Czasownik wybiera formę uzupełnienia

Porównaj ten sam rzeczownik:

<div class="object-series">
  <div class="object-row"><span class="object-badge">czytać</span><p>Marta <span class="object-predicate">czyta</span> <span class="object-mark object-mark--basic"><strong>książkę</strong></span>.</p><span class="object-note">co?</span></div>
  <div class="object-row"><span class="object-badge">potrzebować</span><p>Marta <span class="object-predicate">potrzebuje</span> <span class="object-mark object-mark--basic"><strong>książki</strong></span>.</p><span class="object-note">czego?</span></div>
  <div class="object-row"><span class="object-badge">przyglądać się</span><p>Marta <span class="object-predicate">przygląda się</span> <span class="object-mark object-mark--basic"><strong>książce</strong></span>.</p><span class="object-note">czemu?</span></div>
  <div class="object-row"><span class="object-badge">rozmawiać o</span><p>Marta <span class="object-predicate">rozmawia</span> <span class="object-mark object-mark--basic">o <strong>książce</strong></span>.</p><span class="object-note">o czym?</span></div>
</div>

Dopiero po zauważeniu tej regularności wprowadzamy termin **rekcja**: czasownik wybiera przypadek, przyimek albo inną formę swojego uzupełnienia.

## Jedno dopełnienie może zmienić funkcję

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">zdanie czynne</span><p><span class="subject-mark subject-mark--grammatical"><strong>Marta</strong></span> <span class="object-predicate">napisała</span> <span class="object-mark object-mark--direct"><strong>raport</strong></span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">zdanie bierne</span><p><span class="subject-mark subject-mark--grammatical"><strong>Raport</strong></span> <span class="object-predicate">został napisany</span> przez Martę.</p></div>
</div>

W pierwszym zdaniu **raport** jest dopełnieniem. W drugim staje się podmiotem. Ta transformacja pozwala później odróżnić dopełnienie bliższe od dalszego.

## Forma nie jest tym samym co funkcja

> Marta <span class="object-predicate">jest kierowniczką</span>.

> Marta <span class="object-predicate">kieruje</span> <span class="object-mark object-mark--basic"><strong>zespołem</strong></span>.

Oba wyróżnione wyrazy stoją w narzędniku. **Kierowniczką** należy jednak do orzeczenia imiennego, a **zespołem** uzupełnia czasownik **kieruje** i jest dopełnieniem.

> <span class="subject-mark subject-mark--grammatical"><strong>Muzyka</strong></span> <span class="object-predicate">podoba się</span> <span class="object-mark object-mark--basic"><strong>Marcie</strong></span>.

Wyraz **Marcie** nazywa osobę odbierającą wrażenie, ale podmiotem jest **muzyka**, ponieważ to z nią zgadza się orzeczenie.

## Dopełnienie może mieć różny rozmiar

> Marta <span class="object-predicate">przeczytała</span> <span class="object-mark object-mark--basic">dokładny <strong>raport</strong> o awarii</span>.

> Marta <span class="object-predicate">planuje</span> <span class="object-mark object-mark--indirect"><strong>odwiedzić laboratorium</strong></span>.

> Marta <span class="object-predicate">wie</span>, <span class="object-mark object-mark--clausal"><strong>że raport jest gotowy</strong></span>.

Funkcję dopełnienia może pełnić:

- grupa rzeczownikowa;
- wyrażenie przyimkowe;
- bezokolicznik z własnymi uzupełnieniami;
- całe zdanie podrzędne.

<div class="object-summary">
<h3>Co obejmuje ramka?</h3>
<ul>
  <li>Ramka obejmuje całą grupę pełniącą funkcję dopełnienia.</li>
  <li>Pogrubienie wskazuje wyraz główny grupy albo całą treść bezokolicznikową i zdaniową.</li>
  <li>Przyimek pozostaje wewnątrz ramki, gdy należy do rekcji.</li>
  <li>Określenia rzeczownika mogą znajdować się wewnątrz grupy dopełnienia, choć same są przydawkami.</li>
</ul>
</div>

<div class="object-summary">
<h3>Dopełnienie uzupełnia wcześniejszą analizę zdania</h3>
<p>Nie zastępuje podmiotu ani orzeczenia. Pokazuje, jak główna informacja otwiera miejsce dla kolejnych uczestników, przedmiotów i treści. Dlatego uczymy się go dopiero po zrozumieniu podmiotu i orzeczenia.</p>
