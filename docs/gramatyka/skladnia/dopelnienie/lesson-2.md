# Przypadki dopełnienia

<div class="object-lesson" markdown>

<div class="object-lead">
Dopełnienie może występować w dopełniaczu, celowniku, bierniku, narzędniku albo miejscowniku. Przypadek wynika z rekcji czasownika i nie może być wybierany dowolnie.
</div>

## Dopełniacz

- Zespół <span class="object-predicate">potrzebuje</span> <span class="object-mark object-mark--indirect">dodatkowego czasu</span>.
- Marta <span class="object-predicate">szuka</span> <span class="object-mark object-mark--indirect">dokumentu</span>.
- Kierowca <span class="object-predicate">unika</span> <span class="object-mark object-mark--indirect">gwałtownego hamowania</span>.
- Uczniowie <span class="object-predicate">słuchają</span> <span class="object-mark object-mark--indirect">nauczyciela</span>.

## Celownik

- Marta <span class="object-predicate">pomaga</span> <span class="object-mark object-mark--indirect">koledze</span>.
- Kierowniczka <span class="object-predicate">ufa</span> <span class="object-mark object-mark--indirect">zespołowi</span>.
- Technik <span class="object-predicate">przygląda się</span> <span class="object-mark object-mark--indirect">wykresowi</span>.
- Pracownicy <span class="object-predicate">sprzeciwili się</span> <span class="object-mark object-mark--indirect">zmianie harmonogramu</span>.

## Biernik

- Marta <span class="object-predicate">czyta</span> <span class="object-mark object-mark--direct">raport</span>.
- Technik <span class="object-predicate">widzi</span> <span class="object-mark object-mark--direct">błąd</span>.
- Dyrektorka <span class="object-predicate">spotkała</span> <span class="object-mark object-mark--direct">inspektora</span>.
- Pracownik <span class="object-predicate">otworzył</span> <span class="object-mark object-mark--direct">drzwi</span>.

Biernik jest najczęstszą formą dopełnienia bliższego.

## Narzędnik

- Anna <span class="object-predicate">kieruje</span> <span class="object-mark object-mark--indirect">zespołem</span>.
- Student <span class="object-predicate">interesuje się</span> <span class="object-mark object-mark--indirect">językoznawstwem</span>.
- Technik <span class="object-predicate">posługuje się</span> <span class="object-mark object-mark--indirect">miernikiem</span>.
- Opiekun <span class="object-predicate">zajmuje się</span> <span class="object-mark object-mark--indirect">nowym pracownikiem</span>.

Nie każdy narzędnik jest dopełnieniem. W zdaniu **Marta jedzie autobusem** forma **autobusem** określa środek transportu i jest zwykle analizowana jako okolicznik.

## Miejscownik z przyimkiem

- Marta <span class="object-predicate">myśli</span> <span class="object-mark object-mark--prepositional">o projekcie</span>.
- Zespół <span class="object-predicate">mówi</span> <span class="object-mark object-mark--prepositional">o wynikach</span>.
- Test <span class="object-predicate">polega</span> <span class="object-mark object-mark--prepositional">na porównaniu próbek</span>.
- Technik <span class="object-predicate">zna się</span> <span class="object-mark object-mark--prepositional">na elektronice</span>.

Miejscownik zawsze występuje z przyimkiem.

## Ten sam przyimek, różne funkcje

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">dopełnienie</span><p>Marta <span class="object-predicate">czeka</span> <span class="object-mark object-mark--prepositional">na autobus</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">okolicznik</span><p>Marta <span class="object-predicate">siedzi</span> na ławce.</p></div>
</div>

Sam przyimek nie rozstrzyga funkcji. Trzeba sprawdzić wymaganie czasownika i znaczenie całej konstrukcji.

<h3>Przypadek pokazuje relację z czasownikiem</h3>
Każdy czasownik buduje własny schemat i wybiera formę swojego uzupełnienia.
