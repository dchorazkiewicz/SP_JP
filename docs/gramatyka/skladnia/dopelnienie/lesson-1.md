# Rozpoznawanie dopełnienia i rekcja

<div class="object-lesson" markdown>

<div class="object-lead">
Dopełnienie zależy od orzeczenia i uzupełnia jego znaczenie. Czasownik określa, jakiej formy potrzebuje: przypadku bez przyimka, wyrażenia przyimkowego, bezokolicznika albo całego zdania. Tę właściwość nazywamy <strong>rekcją</strong>.
</div>

## Kolejność analizy

1. Znajdź orzeczenie.
2. Ustal, czego wymaga czasownik.
3. Sprawdź przypadek i przyimek.
4. Oceń, czy składnik uzupełnia znaczenie czasownika.
5. Przy bierniku wykonaj test strony biernej.

## Ten sam rzeczownik w różnych formach

<div class="object-series">
  <div class="object-row"><span class="object-badge">biernik</span><p>Anna <span class="object-predicate">widzi</span> <span class="object-mark object-mark--direct">samochód</span>.</p><span class="object-note">co?</span></div>
  <div class="object-row"><span class="object-badge">dopełniacz</span><p>Anna <span class="object-predicate">szuka</span> <span class="object-mark object-mark--indirect">samochodu</span>.</p><span class="object-note">czego?</span></div>
  <div class="object-row"><span class="object-badge">celownik</span><p>Anna <span class="object-predicate">przygląda się</span> <span class="object-mark object-mark--indirect">samochodowi</span>.</p><span class="object-note">czemu?</span></div>
  <div class="object-row"><span class="object-badge">narzędnik</span><p>Anna <span class="object-predicate">kieruje</span> <span class="object-mark object-mark--indirect">samochodem</span>.</p><span class="object-note">czym?</span></div>
  <div class="object-row"><span class="object-badge">przyimek</span><p>Anna <span class="object-predicate">rozmawia</span> <span class="object-mark object-mark--prepositional">o samochodzie</span>.</p><span class="object-note">o czym?</span></div>
</div>

Każda forma pokazuje inną relację z orzeczeniem.

## Czasownik może otwierać kilka miejsc

> Marta <span class="object-predicate">przekazała</span> <span class="object-mark object-mark--indirect">koledze</span> <span class="object-mark object-mark--direct">dokument</span>.

<div class="object-tree">przekazała
├── komu? → koledze
└── co? → dokument</div>

> Kierowniczka <span class="object-predicate">poinformowała</span> <span class="object-mark object-mark--direct">pracowników</span> <span class="object-mark object-mark--prepositional">o zmianie terminu</span>.

Czasownik może wymagać jednocześnie osoby i treści.

## Rekcja przyimkowa

- Marta <span class="object-predicate">czeka</span> <span class="object-mark object-mark--prepositional">na autobus</span>.
- Marta <span class="object-predicate">myśli</span> <span class="object-mark object-mark--prepositional">o projekcie</span>.
- Zadanie <span class="object-predicate">polega</span> <span class="object-mark object-mark--prepositional">na porównaniu wyników</span>.
- Zespół <span class="object-predicate">rezygnuje</span> <span class="object-mark object-mark--prepositional">z dodatkowego testu</span>.

Przyimek należy tutaj do schematu wymaganego przez czasownik.

## Dopełnienie może być pominięte w kontekście

> Czy Marta przeczytała raport? — Tak, <span class="object-predicate">przeczytała</span>.

Dopełnienie **raport** nie występuje w odpowiedzi, ale można je odtworzyć z pytania.

## Dopełnienie a swobodna informacja

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">wymaganie</span><p>Marta <span class="object-predicate">potrzebuje</span> <span class="object-mark object-mark--indirect">pomocy</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">okoliczność</span><p>Marta <span class="object-predicate">pracuje</span> rano.</p></div>
</div>

Wyraz **pomocy** uzupełnia znaczenie czasownika **potrzebuje**. Wyraz **rano** swobodnie określa czas pracy.

<div class="object-summary">
<h3>Rekcja jest ważniejsza niż samo pytanie</h3>
Dopełnienie powstaje dlatego, że czasownik otwiera określone miejsce i narzuca jego formę. Pytanie pomaga tę zależność zobaczyć.
