# Przeczenie i zmiana przypadku

<div class="object-lesson" markdown>

<div class="object-lead">
Przeczenie czasownika może zmienić formę dopełnienia. Najbardziej widoczna jest zamiana biernika na dopełniacz: <strong>czytam raport</strong>, ale <strong>nie czytam raportu</strong>.
</div>

Zmiana przypadku pokazuje, że zaprzeczenie obejmuje samą czynność i jej obiekt.

## Ten sam rzeczownik, dwa zdania

  <div class="object-comparison-item"><span class="object-comparison-label">czynność wykonana</span><p>Marta przeczytała <span class="object-mark object-mark--direct">książkę</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">czynność niewykonana</span><p>Marta nie przeczytała <span class="object-mark object-mark--negation">książki</span>.</p></div>

> Zespół wykonał <span class="object-mark object-mark--direct">pomiar</span>.

> Zespół nie wykonał <span class="object-mark object-mark--negation">pomiaru</span>.

> Kierowniczka podpisała <span class="object-mark object-mark--direct">umowę</span>.

> Kierowniczka nie podpisała <span class="object-mark object-mark--negation">umowy</span>.

## Gdy czasownik już wymaga dopełniacza

Przeczenie nie powoduje kolejnej zmiany:

> Marta <span class="object-predicate">potrzebuje</span> <span class="object-mark object-mark--indirect">pomocy</span>.

> Marta <span class="object-predicate">nie potrzebuje</span> <span class="object-mark object-mark--indirect">pomocy</span>.

> Technik <span class="object-predicate">szuka</span> <span class="object-mark object-mark--indirect">dokumentu</span>.

> Technik <span class="object-predicate">nie szuka</span> <span class="object-mark object-mark--indirect">dokumentu</span>.

Przeczenie obejmuje orzeczenie, ale nie usuwa rekcji przyimkowej.

## Biernik może pozostać w szczególnym kontraście

W starannej polszczyźnie po zanegowanym czasowniku przechodnim zwykle wybieramy dopełniacz. Biernik może jednak pojawić się, gdy zaprzeczenie nie obejmuje obiektu, lecz przeciwstawia inną część zdania:

> Marta nie przeczytała raport <strong>wczoraj</strong>, lecz dzisiaj.

Taka konstrukcja jest nacechowana i wymaga wyraźnego kontrastu. Neutralna wersja brzmi:

> Marta nie przeczytała <strong>raportu</strong> wczoraj.

## Przeczenie części zdania, nie orzeczenia

> Marta przeczytała <strong>nie raport, lecz instrukcję</strong>.

Orzeczenie **przeczytała** nie jest zaprzeczone. Partykuła **nie** przeciwstawia dwa dopełnienia, dlatego oba zachowują biernik.

> Marta wysłała dokument <strong>nie kierownikowi, lecz zastępczyni</strong>.

Przeczenie dotyczy odbiorcy, a nie samej czynności wysłania.

## Przeczenie wielowyrazowego orzeczenia

<div class="object-comparison">
  <div class="object-comparison-item"><span class="object-comparison-label">brak obowiązku</span><p>Marta <span class="object-predicate">nie musi czytać</span> <span class="object-mark object-mark--negation">raportu</span>.</p></div>
  <div class="object-comparison-item"><span class="object-comparison-label">zakaz czynności</span><p>Marta <span class="object-predicate">ma nie czytać</span> <span class="object-mark object-mark--negation">raportu</span>.</p></div>
</div>

W obu zdaniach dopełnienie przyjmuje dopełniacz, ponieważ cała konstrukcja zawiera zaprzeczoną czynność **czytać**.

<div class="object-summary">
<h3>Przeczenie może przeorganizować przypadek</h3>
Najważniejszy wzór brzmi: <strong>czytam raport — nie czytam raportu</strong>. Trzeba jednak odróżnić przeczenie orzeczenia od kontrastowego „nie raport, lecz instrukcję”.
