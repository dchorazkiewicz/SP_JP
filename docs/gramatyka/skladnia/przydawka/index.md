# Przydawka

<div class="attribute-lesson" markdown>

<div class="attribute-lead">
<strong>Przydawka</strong> określa rzeczownik albo inny wyraz użyty rzeczownikowo. Nie opisuje bezpośrednio czynności, lecz dopowiada, jaka osoba lub rzecz jest omawiana, do kogo należy, z czego się składa albo z czym jest związana.
</div>

## Od rzeczownika do przydawki

> <span class="attribute-mark attribute-mark--adjective">Nowa</span> <span class="attribute-head">kierowniczka</span> podpisała dokument.

Rdzeniem grupy jest rzeczownik **kierowniczka**. Wyraz **nowa** określa ten rzeczownik i pełni funkcję przydawki.

> <span class="attribute-mark attribute-mark--adjective">Nowa</span> <span class="attribute-head">kierowniczka</span> <span class="attribute-mark attribute-mark--genitive">działu logistyki</span> podpisała dokument.

Grupa rzeczownikowa może mieć kilka poziomów:

<div class="attribute-tree">kierowniczka
├── jaka? → nowa
└── czego? → działu
    └── czego? → logistyki</div>

<div class="attribute-summary">
<h3>Przydawka należy do grupy rzeczownikowej</h3>
Najpierw wskaż rzeczownik nadrzędny, a dopiero potem sprawdź, które wyrazy go określają. To pozwala odróżnić przydawkę od dopełnienia i okolicznika.
