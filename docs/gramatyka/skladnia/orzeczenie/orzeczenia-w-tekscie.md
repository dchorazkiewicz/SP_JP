# Orzeczenia w tekście

<div class="predicate-lesson" markdown>

<div class="predicate-lead" markdown>

Ramki pokazują wyłącznie orzeczenia. Okoliczniki, dopełnienia, przydawki, określenia stopnia i grupy liczebnikowe pozostają poza nimi.

    <h2>Nocny sygnał z obserwatorium</h2>
  </div>
  <div class="predicate-reading-text" markdown>

Obserwatorium <span class="predicate-part-linker">było</span> prawie <span class="predicate-part-predicative">gotowe</span> do otwarcia. Technicy <span class="predicate-mark predicate-mark--verbal">naprawiali</span> kopułę i <span class="predicate-mark predicate-mark--verbal">czyścili</span> teleskop.

Lena <span class="predicate-mark predicate-mark--compound">miała przeprowadzić</span> kontrolę. <span class="predicate-mark predicate-mark--compound">Musiała sprawdzić</span> zasilanie. Kiedy <span class="predicate-mark predicate-mark--verbal">weszła</span> do budynku, pomieszczenia <span class="predicate-mark predicate-mark--nominal">były ciche</span>, lecz Lena <span class="predicate-part-linker">nie była</span> całkiem <span class="predicate-part-predicative">pewna</span>.

Przed wejściem do kopuły <span class="predicate-mark predicate-mark--impersonal">należało wyłączyć</span> silnik. Nagle w głośniku <span class="predicate-mark predicate-mark--impersonal">zatrzeszczało</span>, a następnie <span class="predicate-mark predicate-mark--impersonal">usłyszano</span> trzy sygnały.

Drzwi <span class="predicate-mark predicate-mark--nominal">były uchylone</span>, chociaż poprzedniego dnia <span class="predicate-mark predicate-mark--verbal">zostały zamknięte</span>. Lena <span class="predicate-mark predicate-mark--verbal">zauważyła</span>, że strona zeszytu <span class="predicate-mark predicate-mark--nominal">była zapisana</span> świeżym atramentem.

Marek <span class="predicate-mark predicate-mark--verbal">przyjechał</span>. Zeszyt <span class="predicate-part-linker">był</span> <span class="predicate-part-predicative">częścią</span> starego systemu testowego. Urządzenie <span class="predicate-mark predicate-mark--compound">miało odtwarzać</span> dawne komunikaty.

Do północy <span class="predicate-mark predicate-mark--verbal">pozostało</span> piętnaście minut. Lena i Marek <span class="predicate-mark predicate-mark--compound">musieli zdecydować</span>, czy <span class="predicate-part-modal">mogą</span> bezpiecznie <span class="predicate-part-infinitive">obserwować</span> system.

Ponieważ napęd <span class="predicate-mark predicate-mark--nominal">był odłączony</span>, kopuła <span class="predicate-mark predicate-mark--negation">nie poruszyła się</span>. Rejestrator <span class="predicate-mark predicate-mark--verbal">wyłączył się</span> minutę później.

## Kontrola zakresu

- **było gotowe** — wyraz **prawie** pozostaje poza ramką;
- **nie była pewna** — wyraz **całkiem** pozostaje poza ramką;
- **był częścią** — wyrażenie **starego systemu testowego** nie należy do orzeczenia;
- **pozostało** — grupa **piętnaście minut** nie jest częścią orzeczenia;
- **mogą obserwować** — wyraz **bezpiecznie** jest okolicznikiem.
