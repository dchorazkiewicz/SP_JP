# Orzeczenie czasownikowe

<div class="predicate-lesson" markdown>

<div class="predicate-lead">
Orzeczenie czasownikowe jest wyrażone formą czasownika, która samodzielnie orzeka o czynności, zdarzeniu albo stanie. Może być jednym wyrazem albo rozbudowaną formą gramatyczną jednego czasownika.
</div>

## Jeden wyraz, pełne orzeczenie

  <div class="predicate-row"><span class="predicate-badge">przeszłość</span><p>Marta <span class="predicate-mark predicate-mark--verbal">przeczytała</span> raport.</p><span class="predicate-note">r. żeński</span></div>
  <div class="predicate-row"><span class="predicate-badge">przyszłość</span><p>Marta <span class="predicate-mark predicate-mark--verbal">przeczyta</span> raport jutro.</p><span class="predicate-note">czasownik dokonany</span></div>
  <div class="predicate-row"><span class="predicate-badge">rozkaz</span><p><span class="predicate-mark predicate-mark--verbal">Przeczytaj</span> raport przed spotkaniem.</p><span class="predicate-note">2. os. lp.</span></div>

## Orzeczenie niesie informacje gramatyczne

Forma orzeczenia może wskazywać:

- osobę: **czytam, czytasz, czyta**;
- liczbę: **pracuje, pracują**;
- czas: **pracował, pracuje, będzie pracował**;
- tryb: **pracuje, pracowałby, niech pracuje**;
- w czasie przeszłym i warunkowym także rodzaj: **pracował, pracowała, pracowało**.

</div>

## Rozbudowana forma czasu przyszłego

Czas przyszły czasowników niedokonanych jest często wielowyrazowy.

<div class="predicate-series">
  <div class="predicate-row"><span class="predicate-badge">bezokolicznik</span><p>Marta <span class="predicate-mark predicate-mark--verbal">będzie czytać</span> raport.</p><span class="predicate-note">będzie + bezokolicznik</span></div>
  <div class="predicate-row"><span class="predicate-badge">forma przeszła</span><p>Marta <span class="predicate-mark predicate-mark--verbal">będzie czytała</span> raport.</p><span class="predicate-note">będzie + forma na -ł</span></div>
  <div class="predicate-row"><span class="predicate-badge">liczba mnoga</span><p>Uczniowie <span class="predicate-mark predicate-mark--verbal">będą pracowali</span> w bibliotece.</p><span class="predicate-note">jedno orzeczenie</span></div>
</div>

Nie dzielimy konstrukcji **będzie czytać** na dwa niezależne orzeczenia. To jedna forma czasu przyszłego czasownika niedokonanego.

## Czasownik zwrotny

Cząstka **się** współtworzy formę czasownika albo zmienia jego znaczenie.

<div class="predicate-series">
  <div class="predicate-row"><span class="predicate-badge">zwrotność</span><p>Marta <span class="predicate-mark predicate-mark--verbal">przygotowuje się</span> do prezentacji.</p><span class="predicate-note">całe orzeczenie</span></div>
  <div class="predicate-row"><span class="predicate-badge">zmiana stanu</span><p>Niebo <span class="predicate-mark predicate-mark--verbal">rozjaśniło się</span> nad ranem.</p><span class="predicate-note">czasownik z się</span></div>
  <div class="predicate-row"><span class="predicate-badge">wzajemność</span><p>Uczestnicy <span class="predicate-mark predicate-mark--verbal">przywitali się</span> przed spotkaniem.</p><span class="predicate-note">czynność wzajemna</span></div>
</div>

Nie zaznaczamy samego rdzenia bez **się**, jeśli cząstka należy do konstrukcji czasownikowej.

## Strona czynna i bierna

<div class="predicate-comparison">
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">strona czynna</span><p>Marta <span class="predicate-mark predicate-mark--verbal">napisała</span> raport.</p></div>
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">strona bierna</span><p>Raport <span class="predicate-mark predicate-mark--verbal">został napisany</span> przez Martę.</p></div>
</div>

W szkolnej analizie konstrukcja strony biernej **został napisany** jest często traktowana jako rozbudowane orzeczenie czasownikowe. W dokładniejszym opisie jej budowa przypomina także połączenie łącznika z imiesłowem; dlatego wrócimy do niej na stronie o granicach klasyfikacji.

## Orzeczenie a forma nieosobowa

Nie każda forma czasownika jest samodzielnym orzeczeniem.

<div class="predicate-comparison">
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">orzeczenie</span><p>Marta <span class="predicate-mark predicate-mark--verbal">czyta</span> raport.</p></div>
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">bezokolicznik jako uzupełnienie</span><p>Marta chce <strong>czytać</strong> raport.</p></div>
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">imiesłów jako określenie</span><p><strong>Czytając raport</strong>, Marta robiła notatki.</p></div>
</div>

Bezokolicznik i imiesłów mogą należeć do większej konstrukcji, ale nie zawsze tworzą osobne centrum zdania.

## Jedna forma, różne znaczenia

> Marta <span class="predicate-mark predicate-mark--verbal">ma</span> nowy komputer.

Tutaj **ma** oznacza posiadanie i jest samodzielnym orzeczeniem.

> Marta <span class="predicate-mark predicate-mark--compound">ma przygotować</span> prezentację.

Tutaj **ma** wyraża obowiązek lub ustalony plan i współtworzy konstrukcję modalną z bezokolicznikiem.

<div class="predicate-summary">
<h3>Orzeczenie czasownikowe nie musi być krótkie</h3>
Może mieć postać <strong>czyta</strong>, <strong>będzie czytała</strong>, <strong>przeczytałaby</strong>, <strong>przygotowuje się</strong> albo <strong>został napisany</strong>. Najważniejsze jest to, że cała forma orzeka o czynności, zdarzeniu lub stanie.
