# Forma, przeczenie i szyk orzeczenia

<div class="predicate-lesson" markdown>

## Forma pokazuje osobę, liczbę i czas

> <span class="predicate-mark predicate-mark--verbal">Piszę</span> raport.  
> Marta <span class="predicate-mark predicate-mark--verbal">pisze</span> raport.  
> Uczniowie <span class="predicate-mark predicate-mark--verbal">piszą</span> raport.

Czynność jest podobna, lecz forma wskazuje inną osobę i liczbę.

> Wczoraj Marta <span class="predicate-mark predicate-mark--verbal">sprawdzała</span> wyniki.  
> Teraz Marta <span class="predicate-mark predicate-mark--verbal">sprawdza</span> wyniki.  
> Jutro Marta <span class="predicate-mark predicate-mark--verbal">będzie sprawdzała</span> wyniki.

Wyrazy czasu tylko doprecyzowują informację i pozostają poza ramką.

## Fakt, możliwość i polecenie

> Marta <span class="predicate-mark predicate-mark--verbal">zamyka</span> drzwi.  
> Marta <span class="predicate-mark predicate-mark--verbal">zamknęłaby</span> drzwi.  
> <span class="predicate-mark predicate-mark--verbal">Zamknij</span> drzwi.

Pierwsza forma stwierdza fakt, druga przedstawia możliwość, a trzecia wpływa na odbiorcę.

> Ja <span class="predicate-mark predicate-mark--verbal">bym napisał</span> raport.  
> Chętnie **bym** jutro **pomógł**.

W drugim zdaniu orzeczenie **bym pomógł** jest rozdzielone. Pogrubienie wskazuje jego części, ale nie używamy kolorów łącznika i orzecznika, ponieważ jest to forma czasownika, nie orzeczenie imienne.

## Przeczenie nie zmienia typu budowy

> Marta <span class="predicate-mark predicate-mark--verbal">nie przeczytała</span> raportu.  
> Marta <span class="predicate-mark predicate-mark--nominal">nie jest zmęczona</span>.  
> Marta <span class="predicate-mark predicate-mark--compound">nie musi przychodzić</span>.

**Nie** należy do ramki, gdy zaprzecza głównej informacji. Kolor nadal pokazuje budowę czasownikową, imienną albo złożoną.

> Marta <span class="predicate-mark predicate-mark--compound">nie musi przychodzić</span>.  
> Marta <span class="predicate-mark predicate-mark--compound">ma nie przychodzić</span>.

Pierwsze zdanie znosi obowiązek przychodzenia. Drugie nakłada obowiązek niewykonywania czynności.

## Kiedy „nie” pozostaje poza orzeczeniem?

> Marta <span class="predicate-mark predicate-mark--verbal">wysłała</span> nie raport, lecz załącznik.  
> Marta <span class="predicate-mark predicate-mark--verbal">wysłała</span> raport nie wczoraj, lecz dzisiaj.

Przeczenie dotyczy przedmiotu albo czasu, a nie czynności **wysłała**.

## Rozdzielone części różnych typów

> Marta **będzie** jutro **pracować** w bibliotece.  
> Marta <span class="predicate-part-linker">jest</span> od kilku dni wyjątkowo <span class="predicate-part-predicative">spokojna</span>.  
> Marta <span class="predicate-part-modal">musi</span> dokładnie <span class="predicate-part-infinitive">sprawdzić</span> dane.

Orzeczeniami są **będzie pracować**, **jest spokojna** i **musi sprawdzić**.

- Rozdzieloną formę czasownikową zaznaczamy neutralnie pogrubieniem.
- Łącznik i orzecznik zachowują oznaczenia orzeczenia imiennego.
- Część modalna i bezokolicznik zachowują oznaczenia orzeczenia złożonego.

Wyrazy czasu, stopnia i sposobu pozostają poza oznaczeniami.

## Spójniki i partykuły między częściami

> Sekretariat <span class="predicate-part-modal">musiał</span> więc <span class="predicate-part-infinitive">wysłać</span> wyjaśnienie.  
> Czy <span class="predicate-mark predicate-mark--compound">mógłbyś zamknąć</span> drzwi?

**Więc** łączy zdanie z wcześniejszą przyczyną, a **czy** sygnalizuje pytanie. Nie należą do orzeczenia.

## Szyk nie zmienia funkcji

> Marta <span class="predicate-mark predicate-mark--verbal">przeczytała</span> raport.  
> Raport Marta <span class="predicate-mark predicate-mark--verbal">przeczytała</span>.  
> Raport <span class="predicate-mark predicate-mark--verbal">przeczytała</span> Marta.

Zmienia się kolejność i nacisk, ale orzeczeniem pozostaje **przeczytała**.

<div class="predicate-summary">
<h3>Jak kontrolować zakres?</h3>
<ul>
  <li>Włącz elementy tworzące osobę, liczbę, czas i tryb.</li>
  <li>Przeczenie należy do ramki tylko wtedy, gdy zaprzecza głównej informacji.</li>
  <li>Nie używaj kolorów orzeczenia imiennego dla rozdzielonego czasu lub trybu czasownika.</li>
  <li>Spójniki, partykuły pytajne i okoliczniki pozostają poza ramką.</li>
  <li>Zmiana szyku nie zmienia funkcji.</li>
</ul>
