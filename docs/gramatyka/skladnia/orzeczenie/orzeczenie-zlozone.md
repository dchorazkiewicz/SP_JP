# Orzeczenie złożone

<div class="predicate-lesson" markdown>

<div class="predicate-lead" markdown>

Orzeczenie złożone łączy składnik modalny lub fazowy z bezokolicznikiem. Ramki obejmują wyłącznie te składniki. Okoliczniki i inne określenia pozostają poza ramkami, nawet gdy stoją między częściami orzeczenia.

</div>

<div class="predicate-checkpoint">
  <div class="predicate-checkpoint__title">Standard przyjęty w tej publikacji</div>
  <p>Jako orzeczenia złożone oznaczamy jednoznaczne połączenia modalne i fazowe, np. <strong>musi wyjść, może wejść, powinien sprawdzić, ma przygotować, zaczął pracować, przestał mówić</strong>. Przy czasownikach o wyraźnym znaczeniu leksykalnym, takich jak <em>lubić, planować, zamierzać</em>, ramką obejmujemy tylko formę osobową, a bezokolicznik traktujemy jako jej uzupełnienie.</p>
</div>

## Budowa podstawowa

> Marta <span class="predicate-part-modal">musi</span> <span class="predicate-part-infinitive">napisać</span> raport.

<div class="predicate-tree">musi napisać
├── składnik modalny → musi
└── bezokolicznik → napisać</div>

<div class="predicate-series">
  <div class="predicate-row"><span class="predicate-badge">konieczność</span><p>Marta <span class="predicate-mark predicate-mark--compound">musi sprawdzić</span> dane.</p><span class="predicate-note">obowiązek</span></div>
  <div class="predicate-row"><span class="predicate-badge">możliwość</span><p>Marta <span class="predicate-mark predicate-mark--compound">może wysłać</span> raport.</p><span class="predicate-note">możliwość</span></div>

  <div class="predicate-row"><span class="predicate-badge">plan</span><p>Marta <span class="predicate-mark predicate-mark--compound">ma przygotować</span> prezentację.</p><span class="predicate-note">ustalenie</span></div>

## Faza czynności

> Marta <span class="predicate-mark predicate-mark--compound">zaczęła pisać</span> raport.  
> Marta <span class="predicate-mark predicate-mark--compound">przestała pisać</span>.  
> Marta <span class="predicate-mark predicate-mark--compound">skończyła porządkować</span> dokumenty.

Porównaj:

> Marta <span class="predicate-mark predicate-mark--verbal">zaczęła</span> pracę.  
> Marta <span class="predicate-mark predicate-mark--compound">zaczęła pracować</span>.

W pierwszym zdaniu **pracę** jest rzeczownikiem. W drugim bezokolicznik **pracować** współtworzy orzeczenie fazowe.

## Okolicznik między częściami orzeczenia

> Marta <span class="predicate-part-modal">zaczęła</span> ponownie <span class="predicate-part-infinitive">analizować</span> dane.  
> Uczniowie <span class="predicate-part-modal">mogli</span> wreszcie <span class="predicate-part-infinitive">zobaczyć</span> gwiazdozbiory.  
> Uczniowie <span class="predicate-part-modal">musieli</span> długo <span class="predicate-part-infinitive">czekać</span>.

Orzeczenia to **zaczęła analizować**, **mogli zobaczyć** i **musieli czekać**. Wyrazy **ponownie**, **wreszcie** oraz **długo** są okolicznikami.

## Dłuższe orzeczenie

> Marta <span class="predicate-mark predicate-mark--compound">będzie musiała pracować</span> dłużej.

Wszystkie trzy wyrazy należą do orzeczenia. Jeżeli pojawi się określenie, ramki rozdzielamy:

> Marta <span class="predicate-part-modal">będzie musiała</span> jutro przed południem <span class="predicate-part-infinitive">zakończyć</span> raport.

Orzeczenie to **będzie musiała zakończyć**. Wyrażenie **jutro przed południem** jest okolicznikiem czasu.

> Uczniowie <span class="predicate-part-modal">powinni</span>, po dokładnym przeczytaniu instrukcji, <span class="predicate-part-infinitive">założyć</span> rękawice.

Wtrącone wyrażenie nie należy do orzeczenia.

## Przeczenie

> Marta <span class="predicate-mark predicate-mark--compound">nie musi przychodzić</span>.  
> Marta <span class="predicate-mark predicate-mark--compound">nie może przychodzić</span> przez tydzień.  
> Marta <span class="predicate-mark predicate-mark--compound">ma nie przychodzić</span> przez tydzień.  
> Marta <span class="predicate-mark predicate-mark--compound">nie przestała pracować</span>.

## Modalność połączona z orzeczeniem imiennym

> Marta <span class="predicate-mark predicate-mark--compound">powinna być ostrożna</span>.  
> Marta <span class="predicate-mark predicate-mark--compound">może zostać kierowniczką</span>.  
> Drzwi <span class="predicate-mark predicate-mark--compound">powinny pozostać zamknięte</span>.

Jeżeli określenie znajduje się wewnątrz konstrukcji:

> Marta <span class="predicate-part-modal">powinna być</span> wyjątkowo <span class="predicate-part-predicative">ostrożna</span>.

Orzeczenie to **powinna być ostrożna**. Wyraz **wyjątkowo** pozostaje poza ramką.

## Czasownik z bezokolicznikiem, ale nie orzeczenie złożone

W tym materiale stosujemy jeden konsekwentny sposób oznaczania:

> Marta <span class="predicate-mark predicate-mark--verbal">planuje</span> odwiedzić archiwum.  
> Marta <span class="predicate-mark predicate-mark--verbal">zamierza</span> rozpocząć projekt.  
> Marta <span class="predicate-mark predicate-mark--verbal">lubi</span> czytać reportaże.

Orzeczeniami są **planuje**, **zamierza** i **lubi**. Bezokoliczniki są uzupełnieniami tych czasowników i nie otrzymują ramki.

## Dwa czasowniki nie zawsze tworzą jedno orzeczenie

> Marta <span class="predicate-mark predicate-mark--compound">musi napisać</span> raport.  
> Marta <span class="predicate-mark predicate-mark--verbal">pisze</span>, a Paweł <span class="predicate-mark predicate-mark--verbal">sprawdza</span> dane.  
> Marta <span class="predicate-mark predicate-mark--verbal">wyszła</span>, nie zamykając drzwi.

W ostatnim zdaniu forma **nie zamykając** nie jest osobowym orzeczeniem.

<div class="predicate-summary">
<h3>Orzeczenie złożone bez okoliczników</h3>
<ul>
  <li>Ramka obejmuje składnik modalny lub fazowy oraz bezokolicznik.</li>
  <li>Okoliczniki znajdujące się między nimi pozostają poza ramkami.</li>
  <li>Rozdzielone człony zaznaczamy osobno.</li>
  <li>Nie każde połączenie czasownika z bezokolicznikiem jest w tym materiale orzeczeniem złożonym.</li>
</ul>
