# Orzeczenie w zdaniach złożonych

<div class="predicate-lesson" markdown>

<div class="predicate-lead" markdown>

Najpierw ustalamy pełne orzeczenia, a dopiero potem wyznaczamy granice zdań składowych. Spójniki, zaimki względne, okoliczniki i inne składniki zależne pozostają poza ramkami.

</div>

## Dwa centra

> Marta <span class="predicate-mark predicate-mark--verbal">pisze</span> raport, a Paweł <span class="predicate-mark predicate-mark--verbal">sprawdza</span> dane.

Spójnik **a** nie jest orzeczeniem.

> <span class="predicate-mark predicate-mark--verbal">Wiem</span>, że Marta <span class="predicate-mark predicate-mark--verbal">przyjdzie</span>.

Orzeczenia to **wiem** i **przyjdzie**. Spójnik **że** pozostaje poza ramkami.

## Jedno orzeczenie wielowyrazowe

> Marta <span class="predicate-mark predicate-mark--compound">będzie musiała pracować</span> dłużej.

Jeżeli określenie rozdziela składniki:

> Marta <span class="predicate-part-modal">będzie musiała</span> jutro <span class="predicate-part-infinitive">pracować</span> dłużej.

Orzeczenie to **będzie musiała pracować**. Wyraz **jutro** jest okolicznikiem czasu.

## Zdanie względne

> Raport, który Marta <span class="predicate-mark predicate-mark--verbal">napisała</span>, <span class="predicate-mark predicate-mark--verbal">został wysłany</span> rano.

Zaimek **który** i okolicznik **rano** nie należą do orzeczeń.

## Kilka poziomów

> Gdy Marta <span class="predicate-mark predicate-mark--verbal">wróciła</span>, <span class="predicate-mark predicate-mark--verbal">zauważyła</span>, że drzwi <span class="predicate-mark predicate-mark--nominal">były otwarte</span>.

Występują trzy centra: **wróciła**, **zauważyła**, **były otwarte**.

## Kilka orzeczeń przy wspólnym podmiocie

> Marta <span class="predicate-mark predicate-mark--verbal">otworzyła</span> dokument, <span class="predicate-mark predicate-mark--verbal">sprawdziła</span> dane i <span class="predicate-mark predicate-mark--verbal">wysłała</span> raport.

Są to trzy odrębne orzeczenia.

## Imiesłów i bezokolicznik

> <strong>Wracając do domu</strong>, Marta <span class="predicate-mark predicate-mark--verbal">spotkała</span> Annę.

Forma **wracając** nie jest osobowym orzeczeniem.

> Marta <span class="predicate-mark predicate-mark--compound">musi napisać</span> raport.  
> Marta <span class="predicate-mark predicate-mark--verbal">przyszła</span>, aby napisać raport.  
> <span class="predicate-mark predicate-mark--impersonal">Warto czytać</span> codziennie.

W pierwszym zdaniu bezokolicznik należy do orzeczenia złożonego. W drugim jest częścią konstrukcji celu. W trzecim współtworzy centrum bezosobowe.

## Elipsa

> Marta <span class="predicate-mark predicate-mark--verbal">przygotowała</span> raport, a Paweł — prezentację.

W drugim członie pominięto orzeczenie **przygotował**, które można odtworzyć.

## Długi przykład

> Kiedy grupa <span class="predicate-mark predicate-mark--verbal">weszła</span> do sali, prowadząca <span class="predicate-mark predicate-mark--verbal">zauważyła</span>, że ekran <span class="predicate-mark predicate-mark--negation">nie działa</span>. Technik <span class="predicate-mark predicate-mark--compound">musiał wyłączyć</span> zasilanie, zanim <span class="predicate-mark predicate-mark--compound">mógł poprawić</span> połączenie.

<div class="predicate-summary">
<h3>Najpierw orzeczenia, potem granice</h3>
<ul>
  <li>Spójniki i zaimki względne pozostają poza ramkami.</li>
  <li>Jedno orzeczenie wielowyrazowe jest jednym centrum.</li>
  <li>Bezokolicznik może pełnić różne funkcje.</li>
</ul>
