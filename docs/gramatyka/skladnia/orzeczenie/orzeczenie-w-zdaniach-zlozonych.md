# Orzeczenie w zdaniach złożonych

<div class="predicate-lesson" markdown>

<div class="predicate-lead">
W zdaniu złożonym każde zdanie składowe ma własne centrum orzeczeniowe. Liczenie orzeczeń pomaga więc znaleźć granice zdań, ale trzeba odróżniać kilka orzeczeń od wielowyrazowej formy jednego orzeczenia.
</div>

## Dwa orzeczenia — dwa zdania składowe

> Marta <span class="predicate-mark predicate-mark--verbal">pisze</span> raport, a Paweł <span class="predicate-mark predicate-mark--verbal">sprawdza</span> dane.

<div class="predicate-tree">zdanie złożone współrzędnie
├── 1. Marta pisze raport
│   └── orzeczenie → pisze
└── 2. Paweł sprawdza dane
    └── orzeczenie → sprawdza</div>

Spójnik **a** łączy dwa równorzędne zdania składowe.

## Orzeczenie w zdaniu nadrzędnym i podrzędnym

> Wiem, że Marta <span class="predicate-mark predicate-mark--verbal">przyjdzie</span>.

Orzeczenia:

- <span class="predicate-mark predicate-mark--verbal">wiem</span> — zdanie nadrzędne;
- <span class="predicate-mark predicate-mark--verbal">przyjdzie</span> — zdanie podrzędne.

<div class="predicate-tree">wiem
└── co wiem? → że Marta przyjdzie
                 └── orzeczenie → przyjdzie</div>

## Jedno orzeczenie wielowyrazowe to nadal jedno centrum

<div class="predicate-comparison">
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">jedno zdanie</span><p>Marta <span class="predicate-mark predicate-mark--compound">będzie musiała pracować</span> dłużej.</p><p>Trzy formy, ale jedno centrum orzeczeniowe.</p></div>
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">trzy zdania składowe</span><p>Marta <span class="predicate-mark predicate-mark--verbal">pracuje</span>, Paweł <span class="predicate-mark predicate-mark--verbal">odpoczywa</span>, a Anna <span class="predicate-mark predicate-mark--verbal">czyta</span>.</p><p>Trzy niezależne centra.</p></div>
</div>

## Spójniki nie są orzeczeniami

> Marta <span class="predicate-mark predicate-mark--verbal">została</span> w domu, ponieważ <span class="predicate-mark predicate-mark--verbal">padało</span>.

Wyraz **ponieważ** pokazuje relację przyczynową, ale nie orzeka. Centra zdania tworzą **została** i **padało**.

## Zaimki względne też nie są orzeczeniami

> Raport, który Marta <span class="predicate-mark predicate-mark--verbal">napisała</span>, <span class="predicate-mark predicate-mark--verbal">został wysłany</span> rano.

- **napisała** — orzeczenie zdania podrzędnego;
- **został wysłany** — orzeczenie zdania nadrzędnego;
- **który** — zaimek względny, który łączy zdania i pełni funkcję wewnątrz zdania podrzędnego.

## Zdanie podrzędne może poprzedzać nadrzędne

> Kiedy Marta <span class="predicate-mark predicate-mark--verbal">wróciła</span>, Paweł <span class="predicate-mark predicate-mark--verbal">kończył</span> raport.

Kolejność w tekście nie zmienia zależności:

<div class="predicate-tree">Paweł kończył raport
└── kiedy? → kiedy Marta wróciła</div>

## Kilka poziomów zależności

> Gdy Marta <span class="predicate-mark predicate-mark--verbal">wróciła</span>, <span class="predicate-mark predicate-mark--verbal">zauważyła</span>, że drzwi <span class="predicate-mark predicate-mark--nominal">były otwarte</span>.

<div class="predicate-tree">zauważyła
├── kiedy? → gdy Marta wróciła
│              └── orzeczenie → wróciła
└── co zauważyła? → że drzwi były otwarte
                      └── orzeczenie → były otwarte</div>

Mamy trzy zdania składowe i trzy centra orzeczeniowe.

## Zdanie wielokrotnie złożone krok po kroku

> Kiedy wróciłem do domu, zauważyłem, że okno było otwarte, ale nie wiedziałem, kto je otworzył.

### Krok 1. Zaznacz orzeczenia

- <span class="predicate-mark predicate-mark--verbal">wróciłem</span>;
- <span class="predicate-mark predicate-mark--verbal">zauważyłem</span>;
- <span class="predicate-mark predicate-mark--nominal">było otwarte</span>;
- <span class="predicate-mark predicate-mark--negation">nie wiedziałem</span>;
- <span class="predicate-mark predicate-mark--verbal">otworzył</span>.

### Krok 2. Podziel zdanie

<div class="predicate-tree">1. Kiedy wróciłem do domu,
2. zauważyłem,
3. że okno było otwarte,
4. ale nie wiedziałem,
5. kto je otworzył.</div>

### Krok 3. Ustal relacje

<div class="predicate-tree">2. zauważyłem
├── kiedy? → 1. kiedy wróciłem do domu
├── co? → 3. że okno było otwarte
└── ale → 4. nie wiedziałem
             └── czego? → 5. kto je otworzył</div>

## Imiesłowowy równoważnik zdania

> <strong>Wracając do domu</strong>, Marta <span class="predicate-mark predicate-mark--verbal">spotkała</span> Annę.

Forma **wracając** nazywa dodatkową czynność, ale nie jest osobową formą czasownika. W szkolnym opisie całość **wracając do domu** jest imiesłowowym równoważnikiem zdania, a głównym orzeczeniem pozostaje **spotkała**.

Porównaj:

<div class="predicate-comparison">
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">imiesłowowy równoważnik</span><p><strong>Wracając do domu</strong>, Marta <span class="predicate-mark predicate-mark--verbal">spotkała</span> Annę.</p></div>
  <div class="predicate-comparison-item"><span class="predicate-comparison-label">zdanie podrzędne</span><p>Kiedy Marta <span class="predicate-mark predicate-mark--verbal">wracała</span> do domu, <span class="predicate-mark predicate-mark--verbal">spotkała</span> Annę.</p></div>
</div>

W pierwszym przykładzie jest jedno osobowe orzeczenie, w drugim — dwa.

## Bezokolicznik nie zawsze tworzy nowe zdanie

> Marta <span class="predicate-mark predicate-mark--compound">musi napisać</span> raport.

Bezokolicznik **napisać** należy do orzeczenia złożonego.

> Marta <span class="predicate-mark predicate-mark--verbal">przyszła</span>, aby <strong>napisać raport</strong>.

W tradycyjnej analizie **aby napisać raport** jest równoważnikiem zdania podrzędnego celu. Bezokolicznik nie ma własnej osoby, ale tworzy odrębną konstrukcję zależną.

## Elipsa orzeczenia

> Marta przygotowała raport, a Paweł — prezentację.

W drugim członie pominięto orzeczenie **przygotował**, ponieważ można je odtworzyć z pierwszego członu.

<div class="predicate-tree">Marta przygotowała raport,
a Paweł [przygotował] prezentację.</div>

Brak widocznego czasownika nie oznacza braku relacji orzeczeniowej.

## Granice zdań a interpunkcja

- Marta <span class="predicate-mark predicate-mark--verbal">pisze</span>, a Paweł <span class="predicate-mark predicate-mark--verbal">czyta</span>. — przecinek między zdaniami;
- Marta <span class="predicate-mark predicate-mark--verbal">pisze</span> i <span class="predicate-mark predicate-mark--verbal">czyta</span>. — jeden podmiot, dwa orzeczenia; przed pojedynczym **i** zwykle bez przecinka;
- Marta <span class="predicate-mark predicate-mark--verbal">pisze</span>, czyta i poprawia. — szereg orzeczeń w jednym zdaniu pojedynczym rozwiniętym.

Sama liczba orzeczeń nie zawsze wystarcza do ostatecznej klasyfikacji, ponieważ kilka orzeczeń może tworzyć szereg odnoszący się do jednego podmiotu.

## Jednorodne orzeczenia

> Marta <span class="predicate-mark predicate-mark--verbal">otworzyła</span> dokument, <span class="predicate-mark predicate-mark--verbal">sprawdziła</span> dane i <span class="predicate-mark predicate-mark--verbal">wysłała</span> raport.

W szkolnych analizach takie wypowiedzenie bywa traktowane jako zdanie pojedyncze z orzeczeniami szeregowymi albo jako konstrukcja złożona bezspójnikowo i współrzędnie. Klasyfikacja zależy od programu oraz przyjętego modelu, dlatego ważniejsze od samej etykiety jest prawidłowe wskazanie trzech czynności i ich wspólnego wykonawcy.

<div class="predicate-summary">
<h3>Orzeczenia pokazują szkielety zdań składowych</h3>
Najpierw zaznacz wszystkie centra orzeczeniowe, następnie sprawdź, które formy należą do jednego orzeczenia, a dopiero potem wyznacz granice i relacje. To chroni przed uznaniem formy <strong>będzie musiała pracować</strong> za trzy osobne zdania.
