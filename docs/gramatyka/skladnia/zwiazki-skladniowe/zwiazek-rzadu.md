# Związek rządu

<div class="relations-lesson" markdown>

<div class="relations-lead">
W związku rządu wyraz nadrzędny narzuca wyrazowi podrzędnemu określony przypadek albo konstrukcję przyimkową. Forma zależna nie dopasowuje się do centrum, lecz spełnia jego wymaganie.
</div>

## Czasownik rządzi przyimkiem i przypadkiem

- myśleć <span class="relations-mark relations-mark--government">o projekcie</span>;
- czekać <span class="relations-mark relations-mark--government">na autobus</span>;
- zależeć <span class="relations-mark relations-mark--government">od decyzji</span>;
- dążyć <span class="relations-mark relations-mark--government">do porozumienia</span>.

Zmiana przyimka może zmienić znaczenie albo stworzyć konstrukcję niepoprawną.

## Rzeczownik jako wyraz nadrzędny

> analiza <span class="relations-mark relations-mark--government">wyników</span>;

> kierownik <span class="relations-mark relations-mark--government">projektu</span>;

> rozmowa <span class="relations-mark relations-mark--government">o budżecie</span>.

Rzeczownik może zachowywać wymagania znaczeniowo związane z czasownikiem, od którego pochodzi.

## Przymiotnik jako wyraz nadrzędny

- pewny <span class="relations-mark relations-mark--government">wyniku</span>;
- podobny <span class="relations-mark relations-mark--government">do ojca</span>;
- gotowy <span class="relations-mark relations-mark--government">do pracy</span>;
- zależny <span class="relations-mark relations-mark--government">od warunków</span>.

## Przyimek i przypadek

> bez <span class="relations-mark relations-mark--government">raportu</span> — dopełniacz;

> ku <span class="relations-mark relations-mark--government">wyjściu</span> — celownik;

> z <span class="relations-mark relations-mark--government">zespołem</span> — narzędnik;

> o <span class="relations-mark relations-mark--government">projekcie</span> — miejscownik.

Przyimek narzuca przypadek rzeczownikowi, ale cała grupa przyimkowa może jednocześnie zależeć od czasownika albo rzeczownika.

## Zmiana przypadku po przeczeniu

> Marta przeczytała <span class="relations-mark relations-mark--government">raport</span>.

> Marta nie przeczytała <span class="relations-mark relations-mark--government">raportu</span>.

Przeczenie może zmienić biernik na dopełniacz, ale relacja rządu pozostaje.

## Jak rozpoznać rząd?

1. Sprawdź, czy wyraz nadrzędny wymaga konkretnego przypadku.
2. Zmień formę centrum — przypadek wyrazu zależnego zwykle pozostaje wymagany.
3. Porównaj słownikową rekcję: **potrzebować czegoś**, **pomagać komuś**.
4. Nie utożsamiaj każdego przypadku zależnego z rządem bez sprawdzenia relacji.

<h3>Rząd oznacza wymaganie formy</h3>
