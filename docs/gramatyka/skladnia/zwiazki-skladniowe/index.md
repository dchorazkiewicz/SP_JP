# Związki składniowe

<div class="relations-lesson" markdown>

<div class="relations-lead">
<strong>Związki składniowe</strong> pokazują, jak wyrazy łączą się w grupy i zdania. Jeden wyraz jest zwykle nadrzędny, a drugi zależny. Zależność może ujawniać się przez zgodę form, narzucenie przypadku albo samą relację znaczeniową.
</div>

## Wyraz nadrzędny i podrzędny

> <span class="relations-head">raport</span> <span class="relations-arrow">→</span> <span class="relations-mark relations-mark--agreement">szczegółowy</span>

Rzeczownik **raport** jest nadrzędny, ponieważ to on stanowi centrum grupy. Przymiotnik **szczegółowy** jest podrzędny i dostosowuje do niego swoją formę.

> <span class="relations-head">potrzebuje</span> <span class="relations-arrow">→</span> <span class="relations-mark relations-mark--government">raportu</span>

Czasownik **potrzebuje** narzuca rzeczownikowi dopełniacz.

> <span class="relations-head">pracuje</span> <span class="relations-arrow">→</span> <span class="relations-mark relations-mark--adjunction">uważnie</span>

Przysłówek **uważnie** nie odmienia się, ale znaczeniowo zależy od czasownika.

<h3>Zdanie jest siecią zależności</h3>
Nie analizujemy wyrazów osobno. Ustalamy, który element jest centrum, co od niego zależy i w jaki sposób ta zależność jest zaznaczona.
