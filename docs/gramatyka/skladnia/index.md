# Składnia

Składnia opisuje, jak wyrazy tworzą grupy i zdania. Analizę zaczynamy od orzeczenia, następnie wskazujemy podmiot, dopełnienia, przydawki i okoliczniki, a potem badamy związki między wyrazami.

## 1. Orzeczenie

[Przejdź do pełnego rozdziału o orzeczeniu](orzeczenie/){ .md-button .md-button--primary }

Centrum czynności, stanu, zdarzenia lub cechy. Rozdział obejmuje orzeczenia czasownikowe, imienne, złożone i konstrukcje bezosobowe.

## 2. Podmiot

[Przejdź do pełnego rozdziału o podmiocie](podmiot/){ .md-button .md-button--primary }

Osoba, rzecz albo treść, o której się orzeka. Omówione są podmioty gramatyczne, domyślne, logiczne i wieloczłonowe.

## 3. Dopełnienie

[Przejdź do pełnego rozdziału o dopełnieniu](dopelnienie/){ .md-button .md-button--primary }

Składnik wymagany albo otwierany przez czasownik: dopełnienie bliższe, dalsze, przyimkowe, bezokolicznikowe i zdaniowe.

## 4. Przydawka

[Przejdź do pełnego rozdziału o przydawce](przydawka/){ .md-button .md-button--primary }

Określenie rzeczownika: przydawka przymiotna, dopełniaczowa, przyimkowa, rzeczowna, liczebna, zaimkowa i zdaniowa.

## 5. Okolicznik

[Przejdź do pełnego rozdziału o okoliczniku](okolicznik/){ .md-button .md-button--primary }

Informacja o miejscu, czasie, sposobie, stopniu, przyczynie, celu, warunku, przyzwoleniu i innych okolicznościach zdarzenia.

## 6. Związki składniowe

[Przejdź do pełnego rozdziału o związkach składniowych](zwiazki-skladniowe/){ .md-button .md-button--primary }

Rozdział pokazuje:

- wyraz nadrzędny i podrzędny;
- związek zgody;
- związek rządu;
- związek przynależności;
- szeregi współrzędne;
- grupy składniowe;
- analizę wielopoziomową;
- przypadki graniczne.

> Nowa kierowniczka bardzo dokładnie sprawdziła raport zespołu.

W tym zdaniu występuje jednocześnie zgoda, rząd i przynależność, a wyrazy tworzą kilka pięter zależności.

## Kolejność analizy

1. Znajdź orzeczenie.
2. Wskaż podmiot.
3. Rozpoznaj dopełnienia i okoliczniki zależne od orzeczenia.
4. Rozwiń grupy rzeczownikowe przez przydawki.
5. Ustal wyrazy nadrzędne i podrzędne.
6. Nazwij związki: zgodę, rząd, przynależność albo współrzędność.

## Dalsza budowa działu

Następne rozdziały obejmą grupę podmiotu i grupę orzeczenia, zdanie pojedyncze nierozwinięte i rozwinięte, szyk, zdania złożone, interpunkcję, elipsę oraz wykresy zdań.
