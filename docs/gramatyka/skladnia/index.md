# Składnia

Składnia opisuje budowę wypowiedzeń oraz związki między wyrazami.

## Części zdania

- orzeczenie,
- podmiot,
- dopełnienie,
- przydawka,
- okolicznik.

Orzeczenie będzie pierwszym rozwijanym zagadnieniem, ponieważ organizuje zdanie i pozwala ustalić, jakie inne składniki mogą się z nim łączyć.

## Budowa wypowiedzeń

- równoważnik zdania,
- zdanie pojedyncze,
- zdanie złożone współrzędnie,
- zdanie złożone podrzędnie,
- zdania wielokrotnie złożone,
- szyk wyrazów,
- związki składniowe,
- wykresy zdań.

Każde zagadnienie może zostać rozwinięte jako osobny artykuł, zestaw przykładów albo materiał interaktywny.
