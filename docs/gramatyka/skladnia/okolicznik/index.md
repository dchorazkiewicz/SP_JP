# Okolicznik

<div class="adverbial-lesson" markdown>

<div class="adverbial-lead">
<strong>Okolicznik</strong> określa czynność, stan albo zdarzenie. Informuje między innymi, gdzie, kiedy, jak, dlaczego, po co, pod jakim warunkiem albo mimo czego coś się dzieje.
</div>

## Od orzeczenia do okolicznika

> Marta <span class="adverbial-predicate">pracowała</span> <span class="adverbial-mark adverbial-mark--place">w bibliotece</span> <span class="adverbial-mark adverbial-mark--time">wczoraj</span> <span class="adverbial-mark adverbial-mark--manner">bardzo uważnie</span>.

Okoliczniki rozwijają orzeczenie **pracowała**. Każdy odpowiada na inne pytanie:

<div class="adverbial-series">
  <div class="adverbial-row"><span class="adverbial-badge">miejsce</span><p><span class="adverbial-mark adverbial-mark--place">w bibliotece</span></p><span class="adverbial-note">gdzie?</span></div>
  <div class="adverbial-row"><span class="adverbial-badge">czas</span><p><span class="adverbial-mark adverbial-mark--time">wczoraj</span></p><span class="adverbial-note">kiedy?</span></div>
  <div class="adverbial-row"><span class="adverbial-badge">sposób</span><p><span class="adverbial-mark adverbial-mark--manner">bardzo uważnie</span></p><span class="adverbial-note">jak?</span></div>
</div>

<div class="adverbial-summary">
<h3>Okolicznik rozwija orzeczenie</h3>
Najpierw znajdź orzeczenie, a potem sprawdź, które składniki opisują okoliczności czynności lub stanu. Samo pytanie nie wystarcza — ważna jest zależność składniowa.
