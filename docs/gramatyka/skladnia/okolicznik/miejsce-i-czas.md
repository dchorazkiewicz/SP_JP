# Okolicznik miejsca i czasu

<div class="adverbial-lesson" markdown>

<div class="adverbial-lead">
Okolicznik miejsca wskazuje, gdzie, skąd, dokąd albo którędy przebiega czynność. Okolicznik czasu określa moment, początek, koniec, długość lub częstotliwość zdarzenia.
</div>

## Okolicznik miejsca

- Marta pracowała <span class="adverbial-mark adverbial-mark--place">w bibliotece</span>.
- Zespół wrócił <span class="adverbial-mark adverbial-mark--place">z laboratorium</span>.
- Technik poszedł <span class="adverbial-mark adverbial-mark--place">do magazynu</span>.
- Samochód przejechał <span class="adverbial-mark adverbial-mark--place">przez tunel</span>.

## Okolicznik czasu

- Spotkanie rozpoczęło się <span class="adverbial-mark adverbial-mark--time">rano</span>.
- Zespół pracował <span class="adverbial-mark adverbial-mark--time">przez trzy godziny</span>.
- Marta czekała <span class="adverbial-mark adverbial-mark--time">od poniedziałku</span>.
- Technik przychodził <span class="adverbial-mark adverbial-mark--time">codziennie</span>.

## Rzeczownik bez przyimka

> Pracowaliśmy <span class="adverbial-mark adverbial-mark--time">nocą</span>.

> Spotkanie trwało <span class="adverbial-mark adverbial-mark--time">godzinę</span>.

Takie formy również mogą pełnić funkcję okolicznika czasu.

## Okolicznik a dopełnienie

> Marta pojechała <span class="adverbial-mark adverbial-mark--place">do Krakowa</span>. — kierunek ruchu.

> Marta potrzebuje <strong>mapy Krakowa</strong>. — dopełnienie i przydawka, nie okolicznik.

## Okolicznik a przydawka

> Spotkanie odbyło się <span class="adverbial-mark adverbial-mark--time">w poniedziałek</span>.

> Spotkanie <strong>z poniedziałku</strong> zostało przełożone.

<div class="adverbial-summary">
<h3>Miejsce i czas opisują przebieg zdarzenia</h3>
Najważniejsze jest ustalenie, czy wyrażenie rozwija orzeczenie i określa lokalizację, kierunek, moment, długość albo częstotliwość.
