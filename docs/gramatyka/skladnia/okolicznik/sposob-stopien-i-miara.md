# Sposób, stopień i miara

<div class="adverbial-lesson" markdown>

## Możemy opisać przebieg czynności albo nasilenie cechy

Porównaj:

> Marta <span class="adverbial-predicate">czytała</span> raport.

> Marta <span class="adverbial-predicate">czytała</span> raport <span class="adverbial-mark adverbial-mark--manner">uważnie</span>.

> Marta <span class="adverbial-predicate">czytała</span> raport <span class="adverbial-mark adverbial-mark--manner">bardzo uważnie</span>.

Wyraz **uważnie** mówi, jak przebiegało czytanie. Wyraz **bardzo** wzmacnia stopień tej uważności.

## Sposób można wyrazić jednym wyrazem albo grupą

> Marta <span class="adverbial-predicate">mówiła</span> <span class="adverbial-mark adverbial-mark--manner">spokojnie</span>.

> Marta <span class="adverbial-predicate">mówiła</span> <span class="adverbial-mark adverbial-mark--manner">ze spokojem</span>.

> Marta <span class="adverbial-predicate">mówiła</span> <span class="adverbial-mark adverbial-mark--manner">bez pośpiechu</span>.

> Marta <span class="adverbial-predicate">mówiła</span> <span class="adverbial-mark adverbial-mark--manner">tak, jak pokazał trener</span>.

Wszystkie zaznaczone części opisują przebieg wypowiedzi. Takie określenia nazywamy **okolicznikami sposobu**.

<div class="adverbial-concept">
  <span class="adverbial-concept__label">Pojęcie</span>
  <strong>Okolicznik sposobu</strong>
  <p>Opisuje, jak przebiega czynność, stan albo zdarzenie. Może być wyrażony przysłówkiem, grupą z przyimkiem albo całym zdaniem.</p>
</div>

## Sposób a cecha rzeczownika

Porównaj:

<div class="adverbial-comparison">
  <div class="adverbial-comparison-item"><span class="adverbial-comparison-label">opis czynności</span><p>Marta <span class="adverbial-predicate">przeczytała</span> raport <span class="adverbial-mark adverbial-mark--manner">dokładnie</span>.</p><p>Wyraz mówi, jak czytała.</p></div>
  <div class="adverbial-comparison-item"><span class="adverbial-comparison-label">opis rzeczownika</span><p>Marta przeczytała <strong>dokładny raport</strong>.</p><p>Wyraz opisuje raport.</p></div>
</div>

**Dokładnie** jest przysłówkiem i pełni funkcję okolicznika sposobu. **Dokładny** jest przymiotnikiem i pełni funkcję przydawki.

## Stopień pokazuje „jak bardzo”

> Zespół był <span class="adverbial-mark adverbial-mark--manner">bardzo</span> zmęczony.

> Raport był <span class="adverbial-mark adverbial-mark--manner">wyjątkowo</span> szczegółowy.

> Marta pracowała <span class="adverbial-mark adverbial-mark--manner">zbyt</span> długo.

> Wyniki poprawiły się <span class="adverbial-mark adverbial-mark--manner">znacznie</span>.

Wyrazy **bardzo**, **wyjątkowo**, **zbyt** i **znacznie** nie opisują uczestnika ani miejsca. Pokazują nasilenie cechy, sposobu albo zmiany.

Takie określenia nazywamy **okolicznikami stopnia**.

<div class="adverbial-concept">
  <span class="adverbial-concept__label">Pojęcie</span>
  <strong>Okolicznik stopnia</strong>
  <p>Pokazuje, jak silna jest cecha, stan, sposób albo zmiana: <em>bardzo zmęczony</em>, <em>zbyt długo</em>, <em>znacznie wzrosło</em>.</p>
</div>

## Okolicznik może określać przymiotnik albo przysłówek

> Raport był <span class="adverbial-mark adverbial-mark--manner">niezwykle</span> dokładny.

Wyraz **niezwykle** określa stopień cechy **dokładny**.

> Marta pracowała <span class="adverbial-mark adverbial-mark--manner">bardzo</span> spokojnie.

Wyraz **bardzo** określa stopień sposobu **spokojnie**.

W szkolnej analizie oba wyrazy są okolicznikami stopnia, mimo że nie odnoszą się bezpośrednio do czasownika.

## Miara podaje wielkość, odległość albo różnicę

> Samochód <span class="adverbial-predicate">przejechał</span> <span class="adverbial-mark adverbial-mark--manner">sto kilometrów</span>.

> Temperatura <span class="adverbial-predicate">wzrosła</span> <span class="adverbial-mark adverbial-mark--manner">o pięć stopni</span>.

> Marta <span class="adverbial-predicate">spóźniła się</span> <span class="adverbial-mark adverbial-mark--manner">dziesięć minut</span>.

> Poziom wody <span class="adverbial-predicate">obniżył się</span> <span class="adverbial-mark adverbial-mark--manner">o dwa centymetry</span>.

Zaznaczone części nie nazywają rzeczy objętej działaniem. Mierzą długość drogi, wielkość zmiany albo różnicę między oczekiwanym i rzeczywistym czasem.

Takie określenia nazywamy **okolicznikami miary**.

<div class="adverbial-concept">
  <span class="adverbial-concept__label">Pojęcie</span>
  <strong>Okolicznik miary</strong>
  <p>Podaje liczbowy albo porównawczy zakres sytuacji: odległość, wielkość zmiany, różnicę, ilość czasu albo natężenie.</p>
</div>

## Czas trwania a miara różnicy

<div class="adverbial-comparison">
  <div class="adverbial-comparison-item"><span class="adverbial-comparison-label">długość zdarzenia</span><p>Spotkanie <span class="adverbial-predicate">trwało</span> <span class="adverbial-mark adverbial-mark--time">dwie godziny</span>.</p><p>Fragment mówi, jak długo trwało spotkanie.</p></div>
  <div class="adverbial-comparison-item"><span class="adverbial-comparison-label">wielkość opóźnienia</span><p>Marta <span class="adverbial-predicate">spóźniła się</span> <span class="adverbial-mark adverbial-mark--manner">dwie godziny</span>.</p><p>Fragment mierzy różnicę między planowanym i rzeczywistym czasem.</p></div>
</div>

Ta sama grupa wyrazów może więc pełnić inną funkcję znaczeniową w zależności od czasownika.

## Miara a dopełnienie

> Samochód <span class="adverbial-predicate">przejechał</span> <span class="adverbial-mark adverbial-mark--manner">sto kilometrów</span>.

Fragment mierzy długość drogi.

> Samochód <span class="adverbial-predicate">przejechał</span> **most**.

Wyraz **most** nazywa obiekt pokonywany podczas ruchu. W szkolnej analizie jest dopełnieniem bliższym.

Porównaj również:

> Marta <span class="adverbial-predicate">waży</span> **sześćdziesiąt kilogramów**.

Ta konstrukcja podaje miarę cechy osoby, ale nie opisuje sposobu czynności. W szkolnych opracowaniach bywa ujmowana jako okolicznik miary albo szczególny składnik dopełniający. W tym kursie traktujemy ją jako konstrukcję graniczną i nie używamy jej jako podstawowego przykładu okolicznika.

## Narzędzie nie jest zwykłym sposobem

> Technik <span class="adverbial-predicate">otworzył</span> obudowę <span class="adverbial-mark adverbial-mark--manner">śrubokrętem</span>.

Wyraz **śrubokrętem** mówi, czego technik użył. Nie opisuje stylu działania tak jak **ostrożnie**.

W szkolnym opisie narzędzie bywa zaliczane do okolicznika sposobu albo nazywane osobno **okolicznikiem narzędzia**. W tym kursie zaznaczamy je kolorem sposobu, ale zawsze wyjaśniamy, że jego dokładne znaczenie to narzędzie.

<div class="adverbial-checkpoint">
  <div class="adverbial-checkpoint__title">Kolor łączy bliskie szkolne typy, nie zaciera różnicy</div>
  <p>Sposób, stopień, miara i narzędzie mają wspólny zielony system oznaczeń. Tekst musi jednak powiedzieć, czy fragment opisuje przebieg, nasilenie, wielkość czy użyty przedmiot.</p>
</div>

## Stan uczestnika nie jest sposobem

> Marta <span class="adverbial-predicate">wróciła</span> **zmęczona**.

Wyraz **zmęczona** mówi, w jakim stanie była Marta podczas powrotu. Nie odpowiada na pytanie „jak przebiegał powrót?” w takim samym sensie jak **szybko** albo **ostrożnie**.

Porównaj:

> Marta <span class="adverbial-predicate">wróciła</span> <span class="adverbial-mark adverbial-mark--manner">szybko</span>.

> **Zmęczona Marta** wróciła szybko.

W pierwszym zdaniu **szybko** jest okolicznikiem sposobu. W drugim **zmęczona** jest przydawką. Konstrukcja **Marta wróciła zmęczona** znajduje się między zwykłym opisem rzeczownika i orzeczeniem; wrócimy do niej na stronie granicznej.

## Rezultat nie jest zwykłym sposobem

> Technik <span class="adverbial-predicate">pomalował</span> ścianę **na biało**.

Wyrażenie **na biało** nie mówi przede wszystkim, jak technik malował. Mówi, jaki rezultat osiągnął: ściana stała się biała.

Porównaj:

> Technik malował ścianę <span class="adverbial-mark adverbial-mark--manner">starannie</span>.

**Starannie** opisuje przebieg pracy. **Na biało** opisuje wynik tej pracy.

## Krótki tekst

<div class="adverbial-reading">
  <div class="adverbial-reading-header"><h2>Kalibracja urządzenia</h2></div>
  <div class="adverbial-reading-text" markdown>

Technik <span class="adverbial-predicate">ustawiał</span> czujnik <span class="adverbial-mark adverbial-mark--manner">bardzo ostrożnie</span>. Śruby <span class="adverbial-predicate">dokręcał</span> <span class="adverbial-mark adverbial-mark--manner">specjalnym kluczem</span>. Po pierwszym pomiarze temperatura <span class="adverbial-predicate">wzrosła</span> <span class="adverbial-mark adverbial-mark--manner">o trzy stopnie</span>, a wyniki <span class="adverbial-predicate">poprawiły się</span> <span class="adverbial-mark adverbial-mark--manner">znacznie</span>. Urządzenie <span class="adverbial-predicate">działało</span> <span class="adverbial-mark adverbial-mark--manner">wyjątkowo stabilnie</span>.

  </div>
</div>

<div class="adverbial-reading__commentary" markdown>
<strong>Co pokazuje tekst?</strong>

**Bardzo ostrożnie** opisuje sposób i jego stopień. **Specjalnym kluczem** wskazuje narzędzie. **O trzy stopnie** mierzy zmianę temperatury. **Znacznie** i **wyjątkowo** pokazują nasilenie zmiany oraz cechy działania.
</div>

<div class="adverbial-summary">
<h3>Jak nie pomieszać bliskich znaczeń?</h3>
<ul>
  <li>Sposób odpowiada na pytanie, jak przebiega sytuacja.</li>
  <li>Stopień pokazuje, jak silna jest cecha, stan albo sposób.</li>
  <li>Miara podaje wielkość, odległość albo różnicę.</li>
  <li>Narzędzie nazywa przedmiot użyty do działania.</li>
  <li>Stan uczestnika i rezultat wymagają osobnej analizy.</li>
</ul>
