# Okolicznik sposobu, stopnia i miary

<div class="adverbial-lesson" markdown>

<div class="adverbial-lead">
Okolicznik sposobu opisuje, jak przebiega czynność. Okolicznik stopnia i miary określa jej intensywność, zakres, wielkość albo różnicę.
</div>

## Sposób

- Marta pracowała <span class="adverbial-mark adverbial-mark--manner">uważnie</span>.
- Technik działał <span class="adverbial-mark adverbial-mark--manner">zgodnie z instrukcją</span>.
- Zespół odpowiedział <span class="adverbial-mark adverbial-mark--manner">bez wahania</span>.
- Dokument podpisano <span class="adverbial-mark adverbial-mark--manner">elektronicznie</span>.

## Stopień

- Zespół był <span class="adverbial-mark adverbial-mark--manner">bardzo</span> zmęczony.
- Raport był <span class="adverbial-mark adverbial-mark--manner">wyjątkowo</span> szczegółowy.
- Marta pracowała <span class="adverbial-mark adverbial-mark--manner">zbyt</span> długo.
- Wyniki poprawiły się <span class="adverbial-mark adverbial-mark--manner">znacznie</span>.

Okolicznik stopnia może określać czasownik, przymiotnik albo przysłówek.

## Miara

- Samochód przejechał <span class="adverbial-mark adverbial-mark--manner">sto kilometrów</span>.
- Temperatura wzrosła <span class="adverbial-mark adverbial-mark--manner">o pięć stopni</span>.
- Marta spóźniła się <span class="adverbial-mark adverbial-mark--manner">dziesięć minut</span>.
- Urządzenie waży <span class="adverbial-mark adverbial-mark--manner">dwa kilogramy</span>.

## Miara a dopełnienie

> Samochód przejechał <span class="adverbial-mark adverbial-mark--manner">sto kilometrów</span>.

Wyrażenie określa zakres drogi, nie obiekt działania.

> Marta przejechała <strong>most</strong>.

Tutaj rzeczownik wskazuje obiekt pokonywany podczas ruchu i może być analizowany inaczej niż zwykła miara.

## Sposób a stan uczestnika

> Marta wróciła <strong>zmęczona</strong>.

Wyraz **zmęczona** nie opisuje sposobu powrotu, lecz stan Marty. To konstrukcja graniczna, a nie typowy okolicznik sposobu.

## Sposób a narzędzie

> Technik otworzył obudowę <span class="adverbial-mark adverbial-mark--manner">śrubokrętem</span>.

W szkolnym opisie forma narzędnika bywa nazywana okolicznikiem narzędzia albo sposobu. W dokładniejszych opisach może być traktowana jako odrębny składnik semantyczny.

<div class="adverbial-summary">
<h3>Sposób mówi jak, stopień — jak bardzo, miara — w jakim zakresie</h3>
Wszystkie te typy opisują przebieg lub intensywność zdarzenia, ale nie wskazują jego uczestnika.
</div>
