# Fleksja

Fleksja opisuje odmianę wyrazów i zależności między ich formami.

## Zakres działu

- przypadki i deklinacja,
- odmiana rzeczowników,
- odmiana przymiotników,
- odmiana liczebników,
- odmiana zaimków,
- koniugacja czasowników,
- osoba, liczba, rodzaj, czas, tryb i aspekt,
- formy osobowe i nieosobowe,
- formy nieregularne.

Szczegółowe artykuły będą dodawane jako osobne pliki w tym katalogu lub w podkatalogach odpowiadających poszczególnym klasom wyrazów.
