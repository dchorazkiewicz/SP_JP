# Podstawy gramatyki

Ten dział wprowadza pojęcia potrzebne do dalszej nauki gramatyki.

## Plan działu

- język, wypowiedzenie, zdanie i tekst,
- wyraz jako jednostka języka,
- forma wyrazu i znaczenie wyrazu,
- temat fleksyjny i końcówka,
- części mowy i części zdania,
- związki między wyrazami,
- podstawowe terminy gramatyczne.

Każde zagadnienie będzie rozwijane w osobnym pliku Markdown, dzięki czemu dział można uzupełniać bez przebudowywania całej strony.
